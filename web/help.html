fuzzy-stock-system の使い方

手元にある物の数と、その数を確かめた根拠を記録します。数が分からない物は0にせず、不明のまま残せます。

初めて使う

初めて開いたときは簡単操作モードです。新しい物は在庫一覧の入れるで記録し、既にある物は品目の集計とIDから詳細を開いて記録します。セット・依頼・製造などを使うときは、管理の操作モードで高度な操作モードに切り替えます。

品名で探して入力するときは、コードの入力先で品目を選び、名前の一部を入力して検索を押します。候補の名前とコードを確認して…を適用を押すと、入力欄に反映されます。

1台のWindows PCで、1人が使うソフトです。操作するタブは1つにし、起動用の黒い画面を開いたまま使います。

  1. はじめにの案内で、担当者の登録の横にある入力欄で開くを押します。名前を入力して記録するを押してください。
  2. 続いて、置き場所、品目と単位を同じように登録します。場所はコード、品目は品番・コード（文字列のまま保存）に、それぞれを見分けるコードを入れます（先頭の0もそのまま残ります）。場所の登録では記録の対象を選びます。
  3. 在庫一覧の入れるを押します。品目、単位、場所、数量の根拠と数量、実際の日時を入力します。IDは自動で付き（L-0001など）、所属は共通在庫、作業の状態は作業なしになります。
  4. 記録するを押し、操作結果と保存の状態、在庫一覧の表示を確認します。

保管単位は1つの箱・袋・束など、まとめて記録する現物です。IDはその保管単位を区別するための名前で、品目のコードや単位とは別です。IDや案件・用途を自分で指定するときは、高度な操作モードの現物の登録を使います。

例：品目「水2L」、単位「本」、場所「食品棚」を用意します。水12本を数え、数量の根拠を数えた、数量を12として記録すると、L-0001の12本が在庫一覧に出ます。

使う・移す・数え直す

移動先の候補には現在地を出しません。分割の新しいIDは元の末尾番号から未使用の番号を提案します（WATER-01ならWATER-02）。L-0001形式は従来の連番を使い、末尾に数字がないIDは空欄になります。手で書き換えたIDも使えます。

記録後は結果の文が見える位置へ移ります。「回答が必要」「確認が必要」は追加の回答の案内です。入力を直すか操作を切り替えると、前の入力拒否や回答の案内は消えます。保存結果不明・更新競合の案内は残ります。

使った分を記録する

在庫一覧のIDを押し、詳細の使用を選びます。対象は固定されるので、使った数と根拠、使用先、実際の日時を入力してください。12本から2本使ったなら、入力する数は2です。記録後に残りが10本になったことを確認します（従来の現物の登録・使用・移動からも選べます）。

別の操作や対象へ切り替えるとき、未保存の編集があれば破棄の確認が出ます（取り消せば元の入力を保持）。なお、未解消の更新競合や保存結果不明などが残っているとき、および保存処理中は操作を切り替えず、入力欄の下部に理由が表示されます。

使用・分割・一部移動・外へ出す・工程変更など、差し引く数が記録上の数を超えると入力中に注意を示します。材料を複数行使うときも順に試算します（数量不明・概算の残数や、包含の回答待ちでは示しません）。通常の使用や分割では確認事項として残し、親の数量には反映しません。やり直し・修理の交換部品使用などは超過を拒否します。整数の数量欄は最小単位だけを示し、上限を超えたときは拒否の文に上限を示します。小数の数量欄には上限も表示します。

別の場所へ移す・箱を分ける

箱全体を移したときは詳細の移動で移動先を選びます。同じ場所で箱を分けるときは分割、一部だけ別の場所へ移すときはその他の操作の一部を分けて移動を使い、分けた分の新しいIDを確認・入力します。末尾番号のあるIDには未使用の候補が入り、書き換えることもできます。数量と根拠を入力してください。一部を分けて移動は簡単操作モードでも開けます。

現物に合わせて直す

在庫の詳細の数えて確認・訂正を使います（従来の数え直し・訂正・照合からも選べます）。記録が10本でも、数えたら9本だった場合は、対象全体の数9を入力します。差の-1ではありません。原因が分からなければ原因不明のままで構いません。

受け取りとして登録した物では、過去に届いた総数を直すかどうかも選びます。今の残りだけを直す場合は、実際に受け取った数は変えない（現在の残数の確認）を選んでください。

負数で保留された操作を片付ける

確認事項の適用する（保留した操作をこの保管単位の数量へ反映）が負数で拒否されたら、先に数えて確認・訂正で今の数を記録します。保留した操作がその数に含まれていれば、確認事項を閉じる（数量に反映済み・適用しない）で片付けます。含まれているか分からない場合は、確認事項を残して調べてください。

履歴を見る

在庫一覧には品目と場所の呼び名・コードを表示します。IDを押すと、その保管単位の詳細と履歴が開きます。取り分けた物や分割した物も、現物の動きと記録の訂正を分けて確認できます。

共通消耗品を設定する

  1. 行き先登録情報で品目を登録を押し、品目と単位を登録します。袋の中身を個数で見るなら、単位を個、袋にします。
  2. 包装・入り数の設定で品目、包装の単位、中身の単位、入り数、理由を入力します。実際の日時には入り数を適用する時点を入れます。包装を使わなければ不要です。
  3. 共通消耗品・補充基準の設定で品目と共通消耗品として表示するを選びます。集計する単位と、必要なら補充基準・標準依頼数量・標準依頼の単位を設定し、理由を添えて記録してください。
  4. 不足・依頼・案件・用途の共通消耗品で確認します。共通在庫に所属する現物と依頼だけが集計対象です。

設定前の包装は入り数不明のまま残ります。換算した中身の数は実際に数えた数ではありません。残り具合だけを記録した開封分も個数へ換算しません。補充確認が出ても依頼は自動作成しないため、実際に頼んだ分を別途記録します。

基準や対象指定は同じ設定操作で解除でき、解除しても在庫・依頼・過去の履歴は残ります。詳しくは配布ZIPのmanual/02-guide.mdを参照してください。

セットの部品を受け取る

  1. 行き先のセットを開き、使うセット名を選びます。未登録ならセットを登録で製品と構成を登録します。
  2. 構成を確認してこのセットの部品を受け取るを押すと、選んだセットが固定されます。
  3. 案件・用途と製作数を入力します。子構成があれば、組立済み品と自作分の部品のどちらを受け入れるか選びます。
  4. 予定数を展開を押し、今回の受け取り数・根拠・場所と欠品を確認します。欠品があれば手配先を入力してください。
  5. 確認欄を選んで記録するを押します。展開だけでは在庫は増えません。保存後、在庫と履歴で結果を確認します。

登録情報で製品品目を選び、この品目のセットから探すこともできます。セットの詳細からはセットから必要明細を生成とセットで作業を開始へも進めます。セットの変更・削除はその他の操作にあります（削除しても過去の記録は残ります）。

案件ごとの必要明細

製品・用途ごとの標準部品表（テンプレート）は、この画面ではセットと呼びます。必要明細はセットの最上位行だけから作り、子の構成は展開しません。必要明細に出したい部品は、セットの最上位行に直接並べます。

必要明細を生成する

行き先のセットでセット名を選んでセットから必要明細を生成を押すか、必要な数・依頼・発注から操作を選びます。セットから1案件の必要明細だけを生成するときは、セットから必要明細を生成を使い、セット・案件ID・台数（必要日は省略可）を入力して必要明細をプレビューを押してください。内容を確かめ、案件ID・版・必要明細を確認したを選んで記録します。新しい案件は、通常は次の案件・用途の登録の流れで登録と生成を一度に行います。

案件・用途を登録して必要明細まで作る

作業の種類登録情報の登録・変更の操作案件・用途の登録を開き、品番・コード、使うセット、総予定数、必要日（省略可）の順に入力します。使わないのままなら、案件・用途の登録だけを記録します。

  1. 登録済みのコードを入れると、品番・コードのすぐ下に、その案件・用途の内容とこの案件を開くが出ます。この場合は記録できないので、既存の案件・用途を使います。
  2. 最初の受け取りは、今回は記録しないか記録するを選びます。記録する場合は、受け取った台数と欠品の手配先を入力します。
  3. 必要明細をプレビューを押し、案件ID・セットの版・必要明細を確かめます。入力を変えたときは、プレビューし直します。
  4. 受け取りを記録する場合は、プレビューに出た各明細の不足数（欠品リスト）と今回受け取った数を確かめ、実際に合わせて直します。初期値は、今回受け取った数が予定どおり、不足数が0です。
  5. 確認欄を選んで記録するを押します。案件・用途の登録、必要明細の生成、最初の受け取りが1回で記録され、どれかが検査に通らないときは何も記録されません。生成しても現物・受け取り・使用・依頼は、最初の受け取りを記録した分を除いて増えません。

案件の進み具合を見る

行き先の不足・依頼・案件・用途で案件を選ぶと、詳細の先頭に、数量をまとめたカードが出ます。品目の件数（必要明細のある品目・不足ありの品目・不足を判定できない品目・未着の依頼がある品目）が出ます。セットから生成した案件では、総予定数（生成した台数）、作業で使った台数（その案件で作業を始めた台数の合計）、未使用の残り（総予定数から使った台数を引いた数）も出ます。台数が不明な開始があれば「不明」と表示します。作業の開始を記録すると総予定数を超えるときは、超える台数を示して確認を求めます。

生成した必要明細を変更する

生成済み案件は生成した必要明細の変更を使います。案件IDと変更方法を選んで各欄と理由を入力します（セットの最新版に追従だけは理由欄がありません）。変更をプレビューで差分と適用後の必要数を確かめ、差分・適用後の必要数を確認したを選んで記録してください。必要数・根拠・必要日・元資料・改訂の変更、案件独自の明細の追加、明細の除外（必要数を0にして理由を履歴に残す）、台数を変えた再計算、セットの最新版への追従に対応しています。再計算・追従では、手修正・除外・根拠変更済みの明細の新標準値を適用は初期OFFです。未選択なら現在の数量・根拠・除外・由来を保ち、選んだ明細だけを新標準のラベル値へ変えて除外を解除します。

入力と上限の注意点

案件IDの前後に空白があれば入力を残して止まるので、空白を取り除いてプレビューし直します（先頭の0は保たれ、自動採番はありません）。競合時の入力回収は1件64KiBまでです。初回の版・計算基準の版・標準値・現在値・由来は画面と「必要明細」Excelシートで確認でき、余った分は自動移動せず余った分の振り分けで記録します。

工程と次工程の場所を設定する

製作を記録する前に、作業の種類工程の登録・設定の工程の登録で、工程の名前と完了基準を選びます。完了基準が作業終了なら作業終了で完成（渡す前）になり、作業終了後の確認の完了なら作業終了で確認待ち、確認の完了で完成（渡す前）になります。完了基準はその工程で何も記録していない間だけ変更可能です。

次工程へ渡す物を置く場所を、次工程の場所の指定・解除で1か所指定します。指定しないと次の作業へ渡すは記録できません。

使わなくなった工程は利用停止にします。新しい作業の開始に選べなくなるだけで、工程内の物の作業終了・確認の完了・次の作業へ渡すと、記録に使った工程の作業の中断は続けて記録できます。工程は削除できません。

v1.2.0以前の記録を読み込むと、使われていた工程がその名前のまま登録済みになります。登録時の品番・コードが「N」の場所は、次工程の場所に指定された状態になります。不要な工程は利用停止にし、不要な指定は解除してください。更新前のバックアップと旧版へ戻す手順はバックアップ・復元・更新を参照してください。

数量の読み方

数えた
実際に現物を数えた数です。
表示の数（ラベル・パッケージ）
「12本入り」などの外箱や納品書の表示を使った数です。中身を数えたことにはしません。
だいたい
目視や標準値で見積もった数です。使ったり分けたりしても、確かな数へ自動で変わりません。
数が不明
まだ分からない数です。0とは区別し、既知の数量の合計へ足しません。
記録上の数
登録・使用などの記録から計算した現在の数です。今の現物を直接数えた結果とは区別します。
確認が必要
記録の食い違いや未確認の内容があります。対象の詳細と確認・履歴で理由を確認します。

保存を確認する

保存したと表示されたことを確認してから終了します。保存中は操作を重ねず、結果を待ってください。

記録していないと表示されたら、入力欄の下にも同じ理由が出ます。案内に従って入力を直し、もう一度記録するを押します。

保存結果が不明なときは、画面の照会するで結果を調べます。結果を確かめずに同じ内容を新しい操作として登録し直すと、二重の記録になるおそれがあります。一部だけ保存された場合は、保存された分を確認し、画面の案内に従って残りを再試行してください。

更新競合が出たときは、元入力を控え、最新の記録と照合します。照合結果の保存だけでは、元の使用や受け取りは登録されません。

タブ終了後の入力回収は管理で有効にできます。入力中の内容をすべて自動保存する機能ではありません。退避の失敗や容量不足が出たら、元のタブを閉じる前に入力の原文を控えてください。

バックアップ・復元・更新

記録は同じアドレス・ブラウザー・プロファイルの中に保存します。別のPCとは共有しません。InPrivateは使わず、ブラウザーの保存データを消さないでください。在庫記録を外部へ送信する機能はありません。

バックアップを取る

管理の復元用バックアップを保存でJSONファイルを保存し、別に保管します。Excel出力は閲覧用で、復元には使えません。

バックアップへ戻す

現在の記録もバックアップしてから、バックアップから復元で戻したいJSONを選びます。内容と置き換わる範囲を確認して復元するを押し、復元確認が閉じた後に在庫と履歴を確かめてください。

翌日再開する・新版へ更新する

再開時は同じアドレス・ブラウザー・プロファイルで開きます。初期化は不要です。記録が空に見えた場合も、先にアドレスなどを確かめてください。

更新時はバックアップを取り、旧版のタブと起動用の黒い画面を閉じてから新版を起動します（ポート設定を変えていた場合は同じ設定を引き継ぎます）。旧版へ戻すときは更新前のバックアップを使い、更新後の記録を失う範囲を確認してください。

入力回収を有効にした保存先で、それに未対応の旧版を起動しないでください。旧版を確認する場合は、新版のタブと黒い画面を閉じ、旧版のフォルダーにlocal-settings.txtを作り、未使用のポート（例：port=4190）を指定します。別の保存先で旧版を起動し、更新前のバックアップを復元します。詳しくはZIPのREADMEを参照してください。
