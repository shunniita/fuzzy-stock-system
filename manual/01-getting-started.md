# 1. はじめに

[目次](README.md) · 次へ：[作業別ガイド](02-guide.md)

このチュートリアルでは空の保存先に水12本を登録し、2本使った記録を残して、残り10本の状態をバックアップして再開するまでを一通り体験します。

WindowsとMicrosoft Edgeを使います。既存の業務データを変えないよう、練習には普段の記録と分けた通常のブラウザープロファイルを使ってください。InPrivateウィンドウは閉じると記録が消えるため使いません。

## 起動する

1. 配布元のReleaseからZIPをダウンロードします。
2. ZIPを右クリックし、「すべて展開」を選びます。
3. 展開したフォルダー内の`start-local.cmd`をダブルクリックします。
4. 起動用の黒い画面を開いたまま、ブラウザーで開いた在庫画面を確認します。

標準のアドレスは`http://127.0.0.1:4180/`です。1台・1人・1つのタブで、毎回同じアドレス・ブラウザー・プロファイルを使います。配布ZIPではNode.jsなどの開発用ソフトは不要です。ソース一式を取得した場合は、[公開リポジトリの開発者向け手順](https://github.com/shunniita/fuzzy-stock-system#開発者向け)を参照してください。

初めて開いた保存先には、品目や場所が登録されていません。既存の記録が見える場合は初期化せず、練習用の別プロファイルで開き直してください。

## 記録する人・場所・品目を登録する

初回起動時は、在庫画面の「はじめに」に次に登録する項目が順に表示されます。

1. 「担当者（自分の名前）を登録する」の横にある「入力欄で開く」を押します。「担当者の名前」に`練習担当`と入力し、「記録する」を押します。
2. 「置き場所を登録する」の横にある「入力欄で開く」を押します。「品番・コード（文字列のまま保存）」に`S1`、「名称」に`食品棚`と入力します。「記録の対象」の選択欄で「記録の対象」を選び、「記録する」を押します。
3. 「品目と単位を登録する」の横にある「入力欄で開く」を押します。「品番・コード（文字列のまま保存）」に`W`、「呼び名」に`水2L`、「単位（複数は「、」で区切る）」に`本`と入力します。「本の最小単位」は`1（整数）`のままにし、「記録する」を押します。

各操作のあとに「記録した」と表示されることを確認します。3つすべてを登録すると「はじめに」の案内が消え、上部の「登録情報」から登録内容を確認できるようになります。

## 水12本を登録する

続いて、食品棚にある水12本を1つの保管単位（箱やまとまり）として登録します。

1. 上部の行き先で「在庫と入力」を開きます。
2. 入力区画の「作業の種類」で「現物の登録・使用・移動」を選びます。
3. 「操作」で「現物の登録」を選びます。
4. 「新しい保管単位のID」に`WATER-01`、「品目」に`水2L（W）`、「単位」に`本`を指定します。
5. 「案件・用途」は`共通在庫`、「場所」は`食品棚（S1）`、「作業の状態」は`作業なし`、「工程」は`なし`にします。
6. 「数量の根拠」で`数えた`を選び、「数量」に`12`と入力します。「実際の日時」を確認し、「記録する」を押します。

記録すると、在庫一覧に`WATER-01`が追加され、数量が12本と表示されます。`WATER-01`はこの箱を見分けるためのIDで、品目のコード`W`や単位`本`とは別の名前です。

## 2本使ったことを記録する

登録した`WATER-01`から2本を使ったことを記録します。

1. 在庫一覧にある`WATER-01`のボタンを押し、詳細を開きます。
2. 詳細にある「使用」ボタンを押します。入力区画の対象に`WATER-01`が固定された状態で開きます（「操作」で「使用」を選び、対象の保管単位に`WATER-01`を選んでも同じです）。
3. 「数量の根拠」で`数えた`を選び、「数量」に`2`、「使用先の案件・用途・作業」に`日常用`と入力します。
4. 「実際の日時」が登録日時以後であることを確認し、「記録する」を押します。
5. 在庫一覧で`WATER-01`の現在数が10本になったことを確認します。
6. 一覧の`WATER-01`を押し、詳細の履歴に「登録 12本」と「使用 2本」が残っていることを確認します。

使用の「数量」欄には今回使った数（`2`）を入力します。使った後の残り（10本）を入れる欄ではありません。使用後の10本は記録から計算した数として表示され、残りを直接数え直した記録とは区別されます。

## 終了して再開する

最後にバックアップを取り、アプリを終了して再開します。

1. 画面上部の「保存の状態」が「保存した」になっていることを確認します。別の表示になっているときは、先に[保存の状態を確認する](04-troubleshooting.md#保存の状態を確認する)を参照してください。
2. 上部の行き先で「管理」を開き、「復元用バックアップを保存」を押してJSONファイルを保存します。
3. ブラウザーのタブと、起動用の黒い画面を閉じます。
4. 再び`start-local.cmd`をダブルクリックし、同じブラウザー・同じプロファイルで`http://127.0.0.1:4180/`を開きます。
5. 在庫一覧に`WATER-01`の10本と履歴がそのまま残っていることを確認します。再開時の初期化は不要です。

これで基本の流れは完了です。日常の受け取り・移動・数え直しは[作業別ガイド](02-guide.md)、数量の根拠や用語の意味は[画面と用語](03-reference.md)で引けます。バックアップから戻す手順は[バックアップを取り復元する](04-troubleshooting.md#バックアップを取り復元する)を参照してください。
