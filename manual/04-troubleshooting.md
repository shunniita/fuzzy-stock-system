# 4. 困ったとき・保存と復元

[目次](README.md) · 前へ：[画面と用語](03-reference.md) · 次へ：[利用確認チェックリスト](05-checklist.md)

## 記録が見えなくなった

**まず初期化せず、前回と同じ保存先を開いているか確認します。**

1. 前回使ったブラウザーとプロファイルを確認します。
2. アドレスを確認します。`127.0.0.1`と`localhost`、ポート4180と4190は別の保存先です。
3. 前回と同じ組み合わせで開き直します。
4. それでも見えない場合は、保存してある復元用バックアップを確認します。

アプリのフォルダーをコピーするだけでは、ブラウザーの記録は移りません。ブラウザーの保存データを消す前にバックアップを取ってください。

## 保存の状態を確認する

| 表示 | 次にすること |
|---|---|
| 保存した | 結果を確認し、通常どおり続行する |
| 保存できなかった（記録されていない） | 残った入力を確認し、同じ入力欄から記録し直す |
| 一部だけ保存した | 保存済みと未保存の内訳を確認する。画面の照会と「記録し直す」で残りを扱う。最初から別操作として入れ直さない |
| 保存結果不明 | 「照会する」または「再試行する」を使う。未保存と決めつけない。照会で全単位の保存を確認できたら「保存済みとして確定する」を使う |
| 別の画面で記録が保存された | 元入力を控え、「更新競合の照合」で最新記録と比べる。照合結果を保存しただけでは元の業務操作は登録されない |
| 読み込めない | 理由を控える。保存値を消したり、初期化で上書きしたりせず、バックアップと対象版を確認する |

記録には一つのタブを使います。更新競合の未確定の元入力は、そのタブを閉じる前に控えてください。以下の回収機能は、**明示的に有効にした保存先だけ**で使えます。

数が不明・保存結果不明・数量操作の未反映は、それぞれ別の状態です。数が不明を0にしたり、未反映を未保存だと考えて同じ操作を追加したりしないでください。

## タブ終了後の元入力を回収する

1. 保存結果不明・一部保存と入力中の内容を先に確認し、バックアップを取ります。
2. このアプリを開いている、操作中以外のタブを閉じます。**管理**の**タブ終了後の入力回収を有効にする**を押し、確認します。
3. **タブ終了後の入力回収：有効**と表示されたことを確かめます。未有効のままでは、タブ終了後の回収はできません。

有効化後に更新競合を検出すると、元入力を同じブラウザーの保存先へ退避します。**回収した元入力**の件数が増え、保存中や失敗の表示がないことを確認してください。タブを閉じた後も、同じブラウザー・プロファイル・アドレスで開き直すと一覧から確認できます。入力中の内容すべてを常時保存する機能ではありません。

一覧の項目を開き、**原文を控える**で保存してから**この元入力を照合する**を押します。元入力と最新記録を比べ、照合結果・理由・確認者を記録します。この処理は数量を変えません。必要な業務操作は最新記録から別に入力します。

初期化・復元前の世代や、旧版で元世代が分からない入力は参照用です。現在の台帳へ照合結果を直接付けず、原文を控えて別途確認します。**本文を残さず取り下げる**は、控えの確認後に再表示を防ぐ取下げ記録を残します。照合済みという意味ではありません。現在の入力が残っている場合は、先にその入力を確認してから切り替えます。

共有退避は、解消・取下げ済みを含め64件・合計8MiBまでです。自動削除はしません。上限や保存先の容量不足が表示された場合は、元のタブを閉じず原文を控えてください。**共有退避を再試行する**で再確認できますが、保存失敗の表示中はタブ終了後に回収できるとは限りません。

有効化後に旧版から記録が変わると保存を止めます。**管理**の**保存先の原資料を控える**で新旧の資料を保全し、初期化せず照合してください。旧版へ自動的に戻す機能はありません。

## バックアップを取り復元する

### バックアップを取る

1. 保存結果不明や一部保存が残っていないか確認します。
2. **管理**の**復元用バックアップを保存**を押します。
3. ダウンロードされたJSONファイルの名前・日時・保管先を確認します。
4. ブラウザーの保存先とは別にファイルを保管します。

バックアップを自動で別の場所へ複製する機能はありません。頻度と保管先は利用開始前に決めます。

### バックアップから戻す

**復元は現在の記録を置き換えます。今の記録も残す必要がある場合は、先に別名のバックアップを取ってください。**

1. **管理**の**バックアップから復元**を押します。
2. 復元用のJSONを選びます。
3. 確認画面で作成時刻と件数を確認します。違うファイルなら**やめる**を押します。
4. 置き換えてよければ**復元する**を押します。
5. 在庫・履歴・未完了の依頼を確認します。

閲覧用Excelは復元に使えません。復元を練習するときは、業務用と異なる試験用のプロファイルを使います。

入力回収が有効な保存先のバックアップには、未解消の元入力と解消・取下げ記録も含まれます。復元や初期化をしても現存する退避を消さず、過去に解消した入力を未解消として復活させません。この形式は旧版では読めません。未有効の保存先へ復元するときは、先に入力回収を有効にしてください。

## Excelで見たい

**管理**の**閲覧用に出力（Excel・復元には使えない）**で出力します。現在の在庫と当時の履歴では、品目名の基準時点が異なる場合があります。

v1.1.0ではシート名と列名を画面の用語にそろえました。旧版の名前を参照する数式がある場合は、参照先を確認してください。

Excel上で編集しても、アプリの記録は変わりません。訂正はアプリで行ってから再出力してください。先頭ゼロや数式に見える文字列が保持されるかは、[実Excelでの確認](05-checklist.md#実excelで出力を確認する)を行います。

## 更新する・旧版へ戻す

1. 旧版で保存を確認し、復元用バックアップを取ります。旧版のフォルダーも残します。
2. 未確定の入力を確認してからアプリのタブと黒い画面を閉じます。
3. 新版を別フォルダーに展開します。ポート設定を変えていた場合は同じ設定を使います。
4. 新版を起動し、前回と同じブラウザー・プロファイル・アドレスで記録を確認します。

新版が読み込めない場合は初期化せず、旧版とバックアップを保持します。新版で保存した記録を過去の版が読めないことがあります。旧版へ戻す場合は更新前のバックアップを使うため、更新後の記録はそのバックアップに含まれません。試験用の保存先で復元を確認してから戻します。

**入力回収を有効にした後は、同じ保存先で旧版に戻して記録・復元をしないでください。** 新旧の原資料を控え、別の試験用プロファイルで更新前のバックアップを確認します。同じ保存先で旧版が記録すると、新版の保存は中断します。

### 旧版を別の保存先で確認する

1. 新版の「保存した」を確認し、新版のバックアップも別名で保存する。新版のタブと起動用の黒い画面を閉じる。
2. 旧版のフォルダーの `start-local.cmd` と同じ場所に `local-settings.txt` を作り、これまで使っていないポートを指定する。例は `port=4190`。新版の設定は変えない。
3. 旧版を起動し、アドレスが指定したポートであることを確認する。記録が既にある場合は復元せず、別の未使用ポートを選ぶ。
4. 更新前に旧版で保存したバックアップを復元し、内容を確認する。新版で作った記録をこの保存先へ持ち込まない。
5. 新版へ戻るときは旧版のタブと黒い画面を閉じ、新版を元の設定で起動する。

## 起動できない

| 状況 | 確認すること |
|---|---|
| ZIP内のファイルを開いている | 全体を展開し、展開先の`start-local.cmd`を使う |
| ページを開けない | 黒い画面が開いているか、表示されたアドレスと一致するか確認する |
| ポートが使用中 | 既に起動したアプリの黒い画面がないか確認する |
| アクセス拒否・エラー10013 | 黒い画面の番号を控える。予約されたポートや端末設定について管理担当へ確認する |
| 組織の設定で起動できない | エラーを控えて管理担当へ確認する。実行制限を勝手に解除しない |

ポートを変更する場合は、起動用ファイルの隣の`local-settings.txt`に`port=4190`のように1行を書きます。変更後のアドレスは別の保存先になるため、元の記録は元のアドレスで確認します。

## よくある迷い

**「作業の種類」を変えたのに、入力欄が変わりません。** その後で**操作**を選んでください。種類は候補の絞り込みです。

**確認を求められて記録できません。** セットから作業を始める操作などでは、入力内容を確認するチェック欄があります。内容を読み、チェックしてから記録します。入力を変更すると確認が外れる場合があります。

**数え直しで、実際に受け取った数の選択を求められます。** 今の残りだけを直す場合は**実際に受け取った数は変えない（現在の残数の確認）**を選びます。[数え直しの選択肢](02-guide.md#現物を数え直す)も確認してください。

**材料が届いても中断中のままです。** 受け取りと作業の再開は別の記録です。実際に再開したときに**作業の再開（材料の受け取りとは別に記録）**を使います。

**コードが読めません。** 名称や品番・コードで検索し、対象を確かめて手入力で続行します。コードの読取りだけで数量や受け取りを確定しないでください。

**履歴の使用を取り消せません。** 作業の開始の材料として対応付いた使用など、単独で取り消せない記録があります。数量の違いは対象全体を数え直し、[訂正の使い分け](02-guide.md#記録の間違いを直す)を確認します。

解消しない場合は、ソフトの版・ブラウザー・操作名・表示されたメッセージ・期待した結果を控えます。実案件・用途や接続情報を外部へ送らず、再現説明には架空の値を使ってください。
