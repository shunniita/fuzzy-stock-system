# 2. 作業別ガイド

[目次](README.md) · 前へ：[はじめに](01-getting-started.md) · 次へ：[画面と用語](03-reference.md)

日々の作業ごとに、どの画面からどの操作を選ぶかを説明します。用語の意味や上限、Excelシートの構成は[画面と用語](03-reference.md)を参照してください。

## 操作モードを選ぶ

画面には「簡単操作モード」と「高度な操作モード」があります。初めて開いたときは簡単操作モードです。行き先「管理」の「操作モード」で切り替えられます。切り替えても記録・所属・入力中の内容は変わりません。選んだモードはこのブラウザーだけに残り、バックアップには含まれません。

簡単操作モードでは、セット・不足・依頼・案件・用途・製造の区画と、作業の種類から操作を選ぶ欄を出しません。

- 新しく物を入れるときは、在庫一覧の「入れる」を押します。IDは自動で付き（L-0001など）、所属は共通在庫になります。数量の根拠は毎回選びます。
- 既にある物は、品目の集計を押してその品目の保管単位に絞り、IDを押して詳細の「使用」「移動」などから記録します。
- 高度な操作モードで付けた案件・用途・工程・依頼は、詳細と履歴に表示されます。使っても所属は変わりません。

以下の手順は、特に断りがなければ高度な操作モードの画面で説明します。

## 操作を選ぶ

記録を追加するときは、行き先「在庫と入力」の「入力」区画を使います。操作の開き方には2つの方法があります。

### 在庫やセットの詳細から対象を固定して開く

既にある保管単位を操作するときは、在庫一覧のIDを押して詳細を開き、操作ボタンを押します。選んだ保管単位が入力欄に引き継がれるため、対象を選び直す必要はありません。一覧の品目と場所、および詳細の場所には、呼び名とコードを表示します。

- 詳細に直接並ぶボタン：「使用」「移動」「分割」「数えて確認・訂正」
- 「その他の操作」を開くと並ぶボタン：「外へ出す」「一部を分けて移動」「案件・用途の付け替え」「統合」「取り分ける」「取り分けを戻す」「数の食い違いをメモする」「作業の状態の訂正」、および工程の状態に応じた「作業終了」「確認の完了」「次の作業へ渡す」「やり直し・修理を開始」

行き先「セット」でも、セット名を選んで詳細を開くと、「このセットの部品を受け取る」「セットから必要明細を生成」「セットで作業を開始」を対象固定で開けます。「その他の操作」を開くと「セットの登録・変更」「セットの削除」も選べます。

### 入力区画の二段選択から開く

新しい現物の登録や登録情報の変更など、すべての操作は以下の手順で選べます。

1. 「記録する人」を確認します。
2. 1つ目の選択欄「作業の種類」を選びます。
3. 2つ目の選択欄「操作」で実行する操作を選びます。「作業の種類」を変えただけでは入力欄は切り替わりません。
4. 対象・数量・根拠・実際の日時を入力します。確認チェック欄がある操作では、内容を読んでチェックします。
5. 「記録する」を押します。
6. 記録後に表示される結果と「保存の状態」を確認し、一覧・詳細・履歴で結果を確かめます。

「回答が必要」「確認が必要」は、追加の回答を求める案内です。入力を直すか操作を切り替えると、前の入力拒否・回答の案内は消えます。保存結果不明・更新競合など、復旧が必要な案内は残ります。

入力の途中で別の操作や別の対象へ切り替えると、未保存の入力を破棄するか確認が出ます。取り消せば元の入力が残ります。行き先や詳細を閲覧するだけでは入力は切り替わりません。

なお、未解消の更新競合や保存結果不明・一部保存が残っているとき、別画面での保存による再読込待ちや読込不能のとき、および保存処理中は操作を切り替えられません。入力欄の下部に表示される理由を確認し、先に[保存の状態を確認する](04-troubleshooting.md#保存の状態を確認する)の手順で対処してください。

## 品目・場所・案件・用途を用意する

1. 上部の行き先「登録情報」を開き、使いたい品目・場所・案件・用途・担当者が登録済みか確認します。種類（品目・場所・案件・用途・担当者・工程）は、上のサブメニューで切り替えます。表示されるのは選んだ種類の表だけです。
2. 数が多いときは「名称・品番・コードで絞り込み」に文字を入れます。該当する行だけが残り、サブメニューの各種類に当てはまる件数が出ます（例：「品目（0件）」）。
3. 新しく登録するときは、選んだ種類の見出しの下にある「品目を登録」「場所を登録」などを押します。入力欄にその登録の操作が開きます。
4. 名前・コード・単位を入力して「記録する」を押し、一覧に追加されたことを確認します。

登録済みの内容を変えるときは、一覧の品番・コード（場所はコード、担当者と工程は名前）を押します。「選んだ登録情報」に、名称の変更・品番・コードの変更・利用停止などの操作が並びます。押すと、その登録情報を対象に固定した入力が開きます。変更の履歴も同じ場所で確認できます。

正式なコードがまだ決まっていない品目は、「品番・コードなし（仮）」を選んで登録できます。コードが決まったら、同じ品目を選んで「品番・コードの変更・付与」でコードを付けます。品目を作り直す必要はありません。

使わなくなった品目や場所は、選んで「利用停止」で利用停止にします。新規の選択候補から外れるだけで、過去の履歴や現在の在庫は消えません。

入力欄の「作業の種類」で「登録情報の登録・変更」を選んでも、同じ操作を使えます。

### 案件を登録して必要明細まで作る

案件・用途の登録は、使うセットと総予定数まで続けて入力し、必要明細の生成と最初の受け取りまで1回の記録で済ませられます。入力欄は、品番・コード、呼び名、元の資料、使うセット、総予定数、必要日（省略可）、最初の受け取りの順に並びます。

1. 「作業の種類」で「登録情報の登録・変更」を選び、操作「案件・用途の登録」を開きます（行き先「登録情報」で案件・用途の種類を選び、「案件・用途を登録」を押しても開けます）。
2. 「品番・コード」に案件IDを入力します。登録済みの案件・用途のコードを入れると、「品番・コード」欄のすぐ下に、その案件・用途の内容（品番・コード、名称、利用中か利用停止か、生成済みなら総予定数と作業で使った台数）と「この案件を開く」が出ます。この場合、案件の登録は記録できません。「この案件を開く」を押して既存の案件・用途を使ってください。
3. 「使うセット」を選びます。「使わない」のまま記録すると、案件・用途の登録だけが記録されます。セットを使うときは品番・コードが必要で、品番・コードなし（仮）では必要明細を作れません。セットが1件も登録されていないときは「使わない」だけが選べるので、「セットの登録・変更」を押して先にセットを登録します。
4. セットを選ぶと出る欄に、「総予定数」（1以上の整数）と、決まっていれば「必要日（省略可）」を入力します。
5. 「最初の受け取り」を選びます。「今回は記録しない」なら受け取りの欄は出ません。「記録する」を選ぶと、「セットからまとめて受け取り」と同じ入力が、セットと案件を固定して出ます。最初に出るのは「受け取った台数」と「欠品の手配先」です（親子の構成のセットでは各明細の受け取り経路も出ます）。行ごとの欄は、手順6のプレビューに出ます。
6. 「必要明細をプレビュー」を押し、案件ID、セットとその版、総予定数分の必要明細（受け取りを記録する場合はその明細も）を確認します。プレビューの後に入力を変えたときは、プレビューし直します。
7. 受け取りを記録する場合は、プレビューに出た各明細の「不足数（欠品リスト）」と「今回受け取った数」を確かめ、実際に合わせて直します。初期値は、今回受け取った数が予定どおり、不足数が0です。不足数を入れると、今回受け取った数は「予定−不足」になります。
8. 「案件ID・セット・必要明細・受け取りを確認した」にチェックを入れ、「記録する」を押します。案件・用途の登録、必要明細の生成、最初の受け取りが1回の入力として適用され、履歴にはそれぞれの記録が並びます。どれかが検査に通らないときは何も記録されず、入力が残ります。

品番・コードの前後に空白があると記録されません。空白を取り除いて確認してください。必要明細の生成は1案件につき1回です。生成した後に台数や明細を変えるときは[生成した必要明細を変更する](#生成した必要明細を変更する)を使います。

### 案件・用途の進み具合を見る

行き先「不足・依頼・案件・用途」の「表示する案件・用途」で案件を選ぶと、詳細の先頭に、数量をまとめたカードが出ます。

- 品目の件数：「必要明細のある品目」「不足ありの品目」「不足を判定できない品目」「未着の依頼がある品目」を、品目と単位の組で数えます（単位の違う数量は合計しません）。0件でなければ押せて、当てはまる最初の品目へ移ります。必要明細が登録されていない品目は「不足を判定できない品目」に数えます。
- セットから必要明細を生成した案件では、セットと計算基準の版、総予定数、作業で使った台数、未使用の残りも出ます。総予定数は生成した台数です。作業で使った台数は、その案件で始めた作業の台数の合計です（セットを選んだ開始も選ばない開始も数え、開始した品目・単位がセットの製品と同じものだけです）。未使用の残りは、総予定数から作業で使った台数を引いた数です。
- 台数が分からないまま始めた作業があると、作業で使った台数と未使用の残りは「不明」と出ます。0にはなりません。数え直しや付け替えをしても、開始したときの台数のまま数えます。
- 未使用の残りが0より小さいときは「超過」と文字でも出ます。未使用の残りは台数の進み具合で、部品が揃っているかどうかは示しません。部品の不足は件数で確かめます。
- セットから生成した必要明細がない案件は「セットからの必要明細なし」と出ます。生成したセットに製品がないときは、作業で使った台数を数えられません。

作業の開始を記録すると作業で使った台数が総予定数を超えるときは、「確認が必要」として超える台数が出ます。何も保存されていないので、内容を確かめて「確認した」にチェックを入れ、もう一度「記録する」を押すと記録されます。確認したあとに入力を変えると確認は外れ、もう一度「記録する」を押したときに、変えた後の超過台数が出し直されます。

## 開始時点の現物を登録する

導入時や初期棚卸など、最初から手元にある現物を登録するときに使います。依頼に対して届いた物は次節の[受け取りと割り当て](#receipt)を使ってください。

1. 「作業の種類」で「現物の登録・使用・移動」を選びます。
2. 「操作」で「現物の登録」を選びます。
3. 新しい保管単位のID、品目、単位、案件・用途、場所、作業の状態、工程を入力します（具体例は[水12本を登録する](01-getting-started.md#水12本を登録する)を参照）。
4. 数量の根拠と数量、実際の日時を入力して「記録する」を押します。

数が分からない箱は、0を仮置きせず、数量の根拠を`数が不明`、数量を空欄にして登録します。

## 届いた物を受け入れ、依頼へ割り当てる

補充依頼に対して現物が届いたときは、受け取りの記録と同時に「どの依頼の到着分か」を割り当てます。

1. 行き先「不足・依頼・案件・用途」を開き、対象の依頼の未着数を確認して、依頼のID（例：`op1`）を押します。
2. 「選んだ依頼」の「受け取り」を押します。依頼・品目・単位・案件・用途は引き継がれ、入力欄では選び直せません。
3. 新しい保管単位のID、場所、実際に受け取った数量と根拠を入力します。
4. 割り当て1の「届いた数」と「使える数」を入力して「記録する」を押します。一つの受け取りを複数の依頼へ分けるときは、割り当て2・3にほかの依頼を選びます。
5. 記録後、在庫が増えたことと、依頼の未着数・不足数が更新されたことを確認します。

依頼を選ばずに受け取るときは、行き先「不足・依頼・案件・用途」の先頭の「受け取り」を押し、品目・単位・案件・用途と割り当てる依頼を自分で選びます。案件・用途が決まっているときは、その案件・用途の詳細から開くと案件・用途が固定されます。

例えば5個の依頼に対して使える物が3個届いたときは、届いた数を`3`、使える数を`3`にします（残り2個は未着）。後日届いた2個が不良で使えないときは、届いた数を`2`、使える数を`0`にし、不良の現物には「取り分ける」も記録します。未着が0になっても、使える数が足りなければ不足は残ります。

受け取り自体は保存されたものの割り当てだけが拒否された場合は、受け取りをもう一度登録しないでください。「受け取った現物への割り当て」を選び、既存の受け取り記録に対して依頼を割り当てます。

## 共通消耗品と補充基準を設定する

共通在庫として使う消耗品をまとめて監視し、袋や箱の入り数換算と補充の目安を設定する手順です。

数量だけを管理する場合は、品目を登録し、「共通消耗品として表示する」を選んで、「補充基準を設定する」のチェックを外します。包装の設定は、箱や袋の中身を換算したいときに使います。現物の登録では「案件・用途」を「共通在庫」にし、使った数は「使用」、現物に合わせるときは「数えて確認・訂正」で記録します。

1. 行き先「登録情報」で「品目を登録」を押し、使う単位を登録します。袋の中身を個数でも見る場合は、単位に`個、袋`と入力します。小数を使う単位は最小単位も選びます。
2. 包装単位を使う場合は、「包装・入り数の設定」を選び、品目、包装の単位（`袋`）、中身の単位（`個`）、入り数（`10`）、理由を入力します。「実際の日時」にはこの入り数を適用する時点を入れて記録します。バラだけで管理する品目では不要です。
3. 「共通消耗品・補充基準の設定」を選び、対象の品目と「共通消耗品として表示する」を選びます。集計する単位に`個`を指定します。
4. 補充の目安を使う場合は「補充基準を設定する」にチェックを入れ、補充基準（例：`20`）、標準依頼数量（例：`2`）、標準依頼の単位（例：`袋`）、理由を入力して記録します。数量の集計だけを見る場合はチェックを外します。
5. 行き先「不足・依頼・案件・用途」の「共通消耗品」区画で、包装とバラの数、補充確認の表示、既存の依頼を確認します（案件・用途が`共通在庫`の現物と依頼だけが集計されます）。

開封して中身の正確な数が分からない物は、中身の単位で数量の根拠を`数が不明`として登録したうえで、「開けた物の残り具合」で対象と残量区分（多い・半分程度・少ない・ほぼ空）を記録します。残量区分は目安であり、個数へは換算されません。数が分かる分と残量区分だけの分が混在する場合、数が分かる分は「数量の数値部分の小計」として表示します。全体の個数を示す合計ではありません。

設定変更の扱いや入り数換算の仕様は[共通消耗品・工程設定の仕様](03-reference.md#主な上限と保持規則)を参照してください。

## 必要な数と補充依頼を記録する

案件・用途ごとに必要な品目と、それに対する補充依頼・発注・納期回答を記録する手順です。

1. 手入力で案件の必要品目を登録するときは、行き先「不足・依頼・案件・用途」の「表示する案件・用途」で案件を選び、「必要な数の登録」を押します。案件・用途は固定されるので、品目、数量と根拠、元の資料、改訂（決まっていれば必要日）を記録します。足りない分の記録と注文・購入予定の記録も、同じ場所の「その他の操作」から案件を固定して開けます。セットから生成するときは[必要明細を生成する](#必要明細を生成する)を使います。
2. 行き先「不足・依頼・案件・用途」で、必要な数・使用可能な在庫・不足の表示を確認します。
3. 補充を頼んだら、「注文・購入予定の記録」で数量・相手先・依頼日などを記録します。
4. 発注が確定したら「注文の確定」、仕入先から回答が来たら「返事・届く予定日の更新」を記録します。どちらも、依頼のIDを押して「選んだ依頼」から開くと依頼を選び直さずに済みます。取消と割り当ては「その他の操作」にあります。
5. 現物が届いたら、[届いた物を受け入れ、依頼へ割り当てる](#receipt)の手順で記録します。

手入力した必要数を後から変えるときは、案件・用途の詳細で品目の「必要な数の改訂」を押します。セットから生成した案件の必要明細を変えるときは[生成した必要明細を変更する](#生成した必要明細を変更する)を使います。

## 使用・移動・案件・用途の付け替えを行う

「一部を分けて移動」は簡単操作モードでも詳細の「その他の操作」から開けます。「分割」と「一部を分けて移動」の新しいIDは、元のIDがL-0001形式なら従来の連番、独自IDなら末尾の数字を進めた未使用の番号が入ります（例：WATER-01からWATER-02）。末尾に数字がなければ空欄です。書き換えた値は、対象を選び直しても保持します。

使用・外へ出す・分割・一部移動・工程変更・余った分の振り分け・予備の一部交換・交換部品の使用で、差し引く数が記録上の数を超えると注意が出ます。作業の開始やセットで作業を開始する材料も、先の行から順に試算します。数量不明・概算の残数や、包含の回答がまだ必要な入力では注意を出しません。通常の使用や分割では負数になる減算を確認事項として残し、親の数量には反映しません。やり直し・修理の交換部品使用など、数量を確定してから記録する操作は超過を拒否します。整数の数量欄は最小単位だけを示し、上限を超えたときは拒否の文に上限を示します。小数の数量欄には上限も表示します。
「現物の登録・使用・移動」または在庫詳細の操作ボタンから選びます。

| 行いたいこと | 選ぶ操作 | 入力と確認のポイント |
|---|---|---|
| 部品を使った | 使用 | 対象と今回使った数量・根拠・使用先を入力し、記録後の残数を確認する |
| 箱全体を別の場所へ移した | 移動 | 対象と移動先を選ぶ。現在地は移動先の候補に出ない。数量は変わらず場所だけが変わる |
| 箱の一部だけ別の場所へ移した | 一部を分けて移動 | 元の対象、分けた分の新しいID、数量・根拠、移動先を入力し、元と先の両方を確認する |
| 同じ場所で箱を2つに分けた | 分割 | 元の対象、新しいID、分ける数量・根拠を入力する |
| 2つの箱を1つにまとめた | 統合 | 統合元と統合先を選ぶ。品目・場所・状態などの条件が合わない場合は拒否される |
| 別の案件・用途へ回した | 案件・用途の付け替え | 元の対象、付け替え先の案件・用途、新しいID、数量を入力し、両方の案件・用途を確認する |
| 外部へ引き渡した | 外へ出す | 対象・数量・引渡先を入力する。手元の場所移動とは区別される |

分割・一部移動・付け替えでは分けた分に新しい保管単位のIDを付けます（例：`P-01`から分けた箱を`P-01-B`にする）。[新しいIDを決める](03-reference.md#新しいidを決める)を確認し、以降の操作で元と先のIDを取り違えないようにしてください。

箱の一部だけが不良や確認待ちになった場合は、先に「分割」でその分を別IDに分けます。そのあと「取り分ける」で対象を使用可能在庫から外します。

## 現物を数え直す

記録上の数が10個でも、実際に箱全体を数えたら9個だったときの手順です。

在庫一覧で対象のIDを開き、詳細の「数えて確認・訂正」を押すと、対象を固定して手順3から進めます。二段選択から開く場合は手順1から進めます。

1. 「作業の種類」で「数え直し・訂正・照合」、「操作」で「数えて確認・訂正」を選びます。
2. 対象の保管単位を選びます。
3. 「保管単位全体を数えた数」に、今ある全体の数`9`を入力します。差分の`-1`ではありません。
4. 減った原因が分からなければ「原因不明」のままにします。原因が分かるときだけ理由を入力します。
5. 数えた日時を指定して「記録する」を押し、現在数と訂正の履歴を確認します。

### 受け取り記録がある保管単位を数え直すとき

受け取りとして記録した元の保管単位を選ぶと、「実際に受け取った数の扱い（この現物は受け取りとして記録されている）」の選択欄が表示されます（初期値は`選ぶ`）。現在の残数だけを直すのか、過去に届いた総数も直すのかを状況に応じて選びます。

| 状況 | 選ぶ選択肢 | 結果 |
|---|---|---|
| 今の残りだけを直したい（例：10個届いて3個使い、残りを数えたら6個だった） | 実際に受け取った数は変えない（現在の残数の確認） | 届いた総数（10個）は変えず、現在の残数だけを6個に更新する |
| 最初に届いた総数そのものが違っていたと分かった | 実際に受け取った数も、数えた数に訂正する（確定） | 届いた総数も今回入力した数へ訂正する。単なる残数確認には使わない |
| 残りと使用履歴から、届いた総数を逆算して仮置きしたい | 実際に受け取った数を、数えた残りから逆算する（それまでに使った・渡した・分けた数を足す。仮の数） | 減らした記録（3個）と現在の残り（6個）から、届いた総数を仮の数（9個）として求める |

途中の数量が不明な場合や、すでに数え直しを行っている場合などは逆算を選べません。帳尻を合わせるために、実際にはなかった使用や受け取りを架空登録しないでください。

## 工程と次工程の場所を登録する

製作（製造・工程）を記録する前に、「工程の登録・設定」で工程を登録します。工程が1つも登録されていない状態では、作業の開始を記録できません。

1. 行き先「登録情報」の工程の区分で「工程を登録」を押し、工程の名前と完了基準を選んで記録します。
   - 完了基準「作業終了」：作業終了を記録した時点で`完成（渡す前）`になります。
   - 完了基準「作業終了後の確認の完了」：作業終了を記録すると`確認待ち`になり、続いて確認の完了を記録すると`完成（渡す前）`になります。
2. 次工程へ渡す物を置く場所を使う場合は、先に場所を登録してから、工程の区分の「次工程の場所を指定」でその場所を指定します（指定できるのは1か所だけです）。
3. まだ作業や中断を記録していない工程の完了基準を変えるときは、工程の名前を押し、「選んだ登録情報」の「その他の操作」から完了基準の変更を開きます。

次工程の場所を指定しないと「次の作業へ渡す」は記録できません。また、指定した場所には`作業中`・`確認待ち`・`完成（渡す前）`の物を通常の移動や登録で直接置くことはできず、「次の作業へ渡す」で移します。

工程の名称変更・利用停止・完了基準の変更条件や、v1.2.0以前の記録を読み込んだときの扱いは[共通消耗品・工程設定の仕様](03-reference.md#主な上限と保持規則)を参照してください。

## 材料を使って製作する

「作業の種類」で「製造・工程」を選び、工程の進み具合に合わせて操作を記録します。「作業を始める数」にはこれから作る製品の数を入れ、使った部品の数は下の材料欄に入れます（例：製品Rを20台作るためにネジ80本を使うなら、作業を始める数は`20`、材料欄が`80`です）。

1. 「作業の開始」を選び、工程、新しいID、製品、案件・用途、場所、作業を始める数と根拠を入力します。
2. 同じ画面の材料欄で、実際に使った材料の保管単位と数量・根拠を入力して「記録する」を押します。ここで入力した材料は作業開始と同時に引き落とされるため、別に単独の「使用」を記録しないでください。
3. 作業が終わった分には「作業終了」を選び、対象、新しいID、今回終えた製品の数量を入力して記録します。
4. 完了基準が「作業終了後の確認の完了」の工程では、`確認待ち`の対象に「確認の完了」を記録します。
5. 次工程の場所へ渡した分は「次の作業へ渡す」を選び、対象・新しいID・数量を記録します。外部へ出荷・譲渡するときは「外へ出す」を使います。

製作の途中で一部だけを次へ進めると、元の状態に残る分と進んだ分でIDが分かれます。次の操作では、現在の「作業の状態」が合っているIDを選んでください。作業を途中で止めたときは「作業の中断」、再開したときは「作業の再開」を記録します。

## セットを使う

製品・用途ごとの標準部品表（テンプレート）を、この画面では「セット」と呼びます。行き先「セット」を開き、「セットを登録」から製品と構成部品を登録しておくと、以下の3つの作業に使えます。中間組立品を含む2階層構成の作り方は[親子のセットを登録する](06-sets.md)を参照してください。

### 必要明細を生成する

セットの最上位行から、案件ごとの必要明細を作る手順です。

必要明細の生成では子の構成を展開しないため、必要明細に出したい部品をセットの最上位行に直接並べておきます。

#### セットから1案件の必要明細を生成するとき

1. 行き先「セット」で対象のセットを選び、詳細の「セットから必要明細を生成」を押します（「必要な数・依頼・発注」の「セットから必要明細を生成」からも開けます）。
2. 固定された「セット」を確認し、「案件ID」と「台数」（総予定数になります）を入力します（必要日が決まっていれば「必要日（省略可）」も入力します）。登録済みの案件IDを入れると、その案件の内容と「この案件を開く」が出ます。生成できない案件では、その理由も出ます。案件IDは今その品番・コードを持つ案件だけを指します。以前その品番・コードを使っていた案件があれば案内に出ますが、そのまま記録すると新しい案件になります。品番・コードのない（仮の）案件や以前の案件に作るときは、「案件ID」の代わりに「対象」の一覧から選びます。
3. 「必要明細をプレビュー」を押し、案件ID、セットの版、算出された必要明細を確認します。
4. 「案件ID・版・必要明細を確認した」にチェックを入れ、「記録する」を押します。

新しい案件は、通常[案件を登録して必要明細まで作る](#案件を登録して必要明細まで作る)の流れで登録と生成を一度に行います。案件IDの前後に空白がある場合は入力を残したまま停止するため、空白を取り除いてプレビューし直してください。生成しても現物・受け取り・使用・依頼は自動では増えません。

### 生成した必要明細を変更する

セットから生成した案件の必要明細を修正・除外・再計算・最新版へ追従させる手順です。

1. 行き先「不足・依頼・案件・用途」の「表示する案件・用途」で案件を選び、「その他の操作」から「生成した必要明細の変更」を押します。案件IDは固定されます。
2. 「変更方法」を選び、変更方法ごとの入力欄を埋めます。
   - 「必要明細を変更」：対象明細の必要数・根拠・必要日・元資料・改訂を変更
   - 「案件独自の明細を追加」：セットにない品目の必要明細を追加
   - 「明細を除外」：対象明細の必要数を0にし、除外理由を記録（行自体は削除せず履歴に残す）
   - 「台数を変えて再計算」：案件の台数を変えて標準値を再計算
   - 「セットの最新版に追従」：改訂されたセットの最新版の構成・数量を取り込む
3. 「理由」を入力します（「セットの最新版に追従」だけは理由欄がありません）。
4. 「台数を変えて再計算」または「セットの最新版に追従」で、過去に手修正・除外した明細を新しい標準値で上書きしたい場合は、該当明細の「新標準値を適用」（初期値はOFF）にチェックを入れます。
5. 「変更をプレビュー」を押し、変更前後の差分と適用後の必要数を確認します。プレビュー後に入力を変えた場合は、もう一度プレビューし直します。
6. 「差分・適用後の必要数を確認した」にチェックを入れ、「記録する」を押します。

「台数を変えて再計算」で総予定数を作業で使った台数より小さくするときも、超える台数が出て確認を求められます。確認したときだけ記録されます。

手修正した明細や除外した明細が再計算・追従でどう保たれるかの詳細な規則は、[生成した必要明細の変更規則](03-reference.md#生成した必要明細の変更規則)を参照してください。

### 受け取り予定を展開する

セットの構成から、製作数に応じた部品の受け取りと欠品分の補充依頼をまとめて記録する手順です。

1. 行き先「セット」を開き、使うセット名を選びます（「登録情報」で製品品目を選び、「この品目のセット」から開くこともできます）。
2. 構成を確認し、「このセットの部品を受け取る」を押します。案件・用途が先に決まっているときは、その案件・用途の詳細の「セットからまとめて受け取り」から開くと案件・用途が固定され、セットを選びます。
3. 案件・用途と製作数を入力します。中間組立品を含む親子セットでは、その行を「組立済みで受け入れる」か「自作分の部品で受け入れる」かを選びます。
4. 「予定数を展開」を押し、今回受け入れる対象と欠品数を確認します。欠品がある場合は「欠品の手配先」を入力します。
5. 各行の数量・根拠・場所を確認し、確認欄にチェックを入れて「記録する」を押します。
6. 在庫が増えたことと、欠品分の依頼・未着が自動作成されたことを確認します（同じ欠品に対して手動で依頼を重ねて登録しないでください）。

### 作業の開始時の使用候補を出す

セットの構成から、製作開始時に使う材料の候補数を出して作業開始とまとめて記録する手順です。

1. 行き先「セット」でセット名を選び、「セットで作業を開始」を押します（「製造・工程」の同名の操作からも開けます）。
2. 固定された製品・単位・セットを確認し、工程、新しいID、案件・用途、場所、作業を始める数と根拠を入力します。
3. 「使用候補を出す」を押します。「1台あたりの数 × 作業を始める数」が各材料の候補（既定の根拠は`だいたい`）として表示されます。
4. 明細ごとに「使う」か「除外」を選びます。「使う」を選んだ明細では引き落とす保管単位と今回の使用数を確認します（今回実際に使った数が候補と違う場合は実数へ修正し、使用分全体を数えた内訳だけ根拠を`数えた`に変えます）。
5. 同じ材料を複数の箱から使った場合は、「保管単位を分ける」を押して内訳行を追加し、箱ごとの数量に分けて合計を合わせます。
6. セットに含まれない追加の材料を使った場合は、下の「手入力の材料1の保管単位（セットにない材料）」などの欄で対象と使用数・根拠を入力します（手順5の箱違いをここへ重複入力しないでください）。
7. 全明細と算出値との差を確認し、確認欄にチェックを入れて「記録する」を押します。

## 戻ってきた物を扱う

一度外へ出した物が返ってきたときは、返品の仮記録と割り当てを記録します。過去の出庫記録は取り消しません。

1. 「作業の種類」で「やり直し・修理」を選び、「返ってきた物の仮の記録」で品目・場所・数量と根拠・元の情報を記録します（この時点では在庫数に加算されません）。
2. 続いて「返ってきた物の仮の記録の割り当て」を選び、手順1の仮記録を選びます。
3. 返ってきた物がすでに現在の在庫数に含まれているかを確認します。
   - 含まれている場合：既存の保管単位を選んで対応付けます。
   - 含まれていない場合：新しいID・品目・単位・案件・用途・場所を指定します。
4. 理由を入力し、確認欄にチェックを入れて「記録する」を押します。割り当てた現物は取り分け（確認待ち）の状態になります。

返ってきた物をやり直しや修理へ回すときは、「返ってきた物のやり直し・修理を開始」を選びます。対象・工程・新しいID・数量・理由を入力して記録してください（数量が不明な場合は先に数えて確認します）。

一方、まだ外へ出していない手元の`完成（渡す前）`の物をやり直すときは、在庫詳細の「その他の操作」または「やり直し・修理」から「やり直し・修理を開始」を選びます。交換部品を使った場合や取り外した部品を廃棄・回収した場合は、同じ「やり直し・修理」内の各操作で別途記録します。

## 記録の間違いを直す

間違えた内容に応じて、以下の操作を使い分けます。

| 状況 | 使う操作（数え直し・訂正・照合／受け取り・割り当て・返却） |
|---|---|
| 現在の数量が合わない（原因は不明でもよい） | 数えて確認・訂正 |
| 数の食い違いに気づいたが、すぐには数え直せない | 数の食い違いをメモする |
| 記録した使用や出庫そのものが誤りだった | 間違えた記録の取り消し |
| 実際に物が動いた日時だけを直したい | 実際の日時の訂正 |
| 受け取りで記録した「届いた総数」が違っていた | 実際に受け取った数の訂正 |
| 依頼へ割り当てた「届いた数」「使える数」が違っていた | 割り当ての訂正 |

取り消しと日時の訂正は、行き先「確認・履歴」の履歴で操作のID（例：`op2`）を押し、「選んだ記録」から開くと対象を選び直さずに済みます。取り消しは、まだ取り消していない使用・引渡しにだけ出ます。実際に受け取った数の訂正は、受け取った保管単位の詳細の「その他の操作」からも開けます。

作業の開始にひも付いた材料の使用は、単独では取り消せません。推計で記録した材料の使用数を後から直す場合も含め、対象の保管単位全体を「数えて確認・訂正」で数え直してください。

紙のメモや別資料の記録を後からまとめて入力するときは、「別記録・元の資料からの後入力」を使います。数え直しより前の日時の動きを後入力する場合は、その動きがすでに数え直し後の現在数に含まれているかを必ず確認し、二重に増減させないようにしてください。

## 確認が必要な記録を調べる

後入力や更新競合などで確認が必要な記録が生じたときは、上部の行き先「確認・履歴」に件数が表示されます。

1. 行き先「確認・履歴」を開き、確認が必要になった理由・対象の保管単位・元の操作内容を確認します。
2. 対象の保管単位の詳細と、手元の元資料を見比べます。
3. 必要であれば、先に「数えて確認・訂正」などで現在の数量を確定させます。
4. 確認事項の表でIDを押し、「選んだ確認事項」の「確認事項を片付ける」から解消方法を選んで記録します。見つかった物の仮の記録では、既存の保管単位への対応付けと新しい保管単位としての登録も同じ場所から開けます。登録では、仮の記録に書いた品目と場所が初めから選ばれています。

「適用する（保留した操作をこの保管単位の数量へ反映）」を選ぶと、保留されていた操作が現在の数量へ反映されます。未確認の件数を0にするだけの目的で押さないでください。

「負数になるため未反映」の確認事項で、適用しても負数になるときは、先に対象の保管単位の「数えて確認・訂正」で今の数を記録します。保留した操作がその数に含まれていれば、「閉じる（数量に反映済み・適用しない）」を選びます。たとえば50個から60個使ったと記録し、今の現物が0個なら、0個を数えて記録してから閉じます。含まれているか分からない場合は、確認事項を残して調べてください。
