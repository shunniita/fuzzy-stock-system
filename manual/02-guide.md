# 2. 作業別ガイド

[目次](README.md) · 前へ：[はじめに](01-getting-started.md) · 次へ：[画面と用語](03-reference.md)

## 操作を選ぶ

記録を追加するときは、**在庫と入力**の**入力**区画を使います。

1. **記録する人**を確認します。
2. 一つ目の選択欄、**作業の種類**を選びます。
3. 二つ目の選択欄、**操作**を選びます。種類だけでは入力欄は切り替わりません。
4. 対象・数量・根拠・実際の日時を入力します。確認チェック欄がある操作では、内容を読んでチェックします。
5. **記録する**を押します。
6. 操作結果と**保存の状態**を確認し、対象の一覧・詳細・履歴で結果を確かめます。

エラーが出たときは、その操作がすべて未反映とは限りません。特に受け取りと複数の割り当てでは、保存された部分が残る場合があります。[保存の状態](04-troubleshooting.md#保存の状態を確認する)を先に確認してください。

## 品目・場所・案件・用途を用意する

1. **登録情報**で、使いたい品目・場所・案件・用途・担当者が既にないか確認します。
2. 新しく登録する場合は**在庫と入力**へ戻り、**登録情報の登録・変更**を選びます。
3. **登録情報：品目の登録**など、登録する種類の操作を選び、名前・コード・単位などを入力します。
4. 記録した後、**登録情報**で登録内容を確認します。

正式コードがまだない品目は、**品番・コードなし（仮）**を選んで登録できます。後から**登録情報：品番・コードの変更・付与（仮の正式化を含む）**で同じ品目にコードを付けます。コードを付けるために品目を作り直す必要はありません。

使わなくなった品目は**登録情報：利用停止（過去の記録は消さない）**を使います。過去の履歴を消す操作ではありません。

## 開始時点の現物を登録する

最初から手元にある物は、**現物の登録・使用・移動**の**登録（開始時点の現物・既にある物。依頼への受け取りは「受け取り」を使う）**で登録します。[水12本の登録例](01-getting-started.md#水12本を登録する)を参考にしてください。

品目・案件・用途・場所・数量の根拠を確認します。数が分からないときは数が不明を使い、0を仮置きしません。依頼に対して今届いた物は、次の受け取り操作を使います。

## 届いた物を受け入れ、依頼へ割り当てる

**割り当て**は、届いた現物を「どの依頼の到着分か」に対応付けることです。

1. **不足・依頼・案件・用途**で対象の依頼と未着分を確認します。
2. **在庫と入力**で**受け取り・割り当て・返却**を選び、**受け取り（届いた数を記録。依頼への割り当てつき）**を選びます。
3. 新しい保管単位のID、品目、単位、案件・用途、場所、届いた数量と根拠を入力します。
4. 割り当てる依頼を選び、今回の**届いた数**と**使える数**を入力します。
5. 記録後、在庫が増えたことと、依頼の未着・不足の変化を確認します。

例えば5個の依頼に、使える物が3個届いた場合、届いた数3・使える数3とします。残り2個は未着です。後日2個が届いても不良で使えない場合は、その分の使える数を0とします。未着が0になっても、不足が解消したとは限りません。不良の現物は、取り分けも記録します。

割り当てだけが拒否され、受け取りが残った場合は、受け取りをもう一度登録しません。**受け取った現物への割り当て（拒否のあとの再割り当てなど）**で、既存の受け取りを選んで対応付けます。

## 必要な数と補充依頼を記録する

**必要な数・依頼・発注**の操作を使います。

1. **必要な数の登録（案件・用途ごとの必要品目・必要な数）**で、案件・用途・品目・数量と根拠・元の資料・改訂を記録します。必要日が決まっていれば指定します。
2. **不足・依頼・案件・用途**で、必要な数と使用可能な在庫、不足の表示を確認します。数が分からない物がある場合は、無理に不足を確定しません。
3. 実際に補充を依頼したら、**注文・購入予定の記録（依頼しただけでは在庫に数えない）**で数量・相手先・依頼日などを記録します。
4. 発注を確認したら**注文の確定（依頼とは別の記録）**、回答が来たら**返事・届く予定日の更新**を使います。
5. 到着時は前節の受け取り・割り当てを行います。

必要な数を変更するときは**必要な数の改訂（改訂前後を履歴に残す）**を使います。不足の手動申告は、不足を知らせる記録です。依頼や現物の登録が自動で行われるものではありません。

## 使用・移動・案件・用途の付け替えを行う

**現物の登録・使用・移動**から選びます。

| 行いたいこと | 選ぶ操作 | 入力と確認 |
|---|---|---|
| 部品を使った | 使用 | 対象と使った数量・根拠・使用先を入力。残数を確認 |
| 箱全体を移した | 移動（保管単位全部） | 対象と移動先を選ぶ。数量はそのままで場所が変わる |
| 一部だけ別の場所へ移した | 一部を分けて移動 | 元の対象、分けた分の新しいID、数量・根拠、移動先を入力。元と先を確認 |
| 同じ場所で箱を分けた | 分割（同じ場所で分ける） | 元の対象、新しいID、分ける数量・根拠を入力 |
| 箱をまとめた | 統合 | 統合元と統合先を選ぶ。条件が合わず拒否されたら対象を確認 |
| 別の案件・用途へ回した | 案件・用途の付け替え（場所は変えない） | 元の案件・用途の対象、先の案件・用途、新しいID、数量を入力。両方の案件・用途を確認 |
| 外へ渡した | 外へ出す（譲渡・持ち出し） | 対象・数量・引渡先を入力。手元の移動と区別 |

分けた分には、入力した新しいIDが付きます。例えば`P-01`から分けた箱を`P-01-B`とするなど、まだ使っていない名前を付けます。[IDの付け方](03-reference.md#新しいidを決める)を確認し、次の操作では元と分割後のIDを取り違えないよう、品目・場所・案件・用途も確認してください。

一部だけ不良の場合は、その分を分割してから**取り分ける（不良・使用可否確認待ち・返却待ち・予備）**を使います。取り分けは、その保管単位を使用対象から外す操作です。

## 現物を数え直す

台帳が10個でも、実際に箱全体を数えて9個だった場合の手順です。

1. **数え直し・訂正・照合**の**数えて確認・訂正（原因不明でもよい）**を選びます。
2. 対象の保管単位を選びます。
3. **保管単位全体を数えた数**に`9`を入力します。差の`-1`ではありません。
4. 原因が分からなければ**原因不明**のままにします。分かる場合は原因を記述します。
5. 数えた日時を指定して記録し、現在数と訂正の履歴を確認します。

受け取りとして記録した元の保管単位を選ぶと、**実際に受け取った数の扱い（この現物は受け取りとして記録されている）**が表示されます。初期値は**選ぶ**です。現在の残りと、過去に届いた総数のどちらを直すか、毎回選択します。

**今の残りだけを直す場合は「実際に受け取った数は変えない（現在の残数の確認）」を選びます。** 例えば10個届いて3個使用し、残りを数えたら6個だった場合、現在数を6個に直し、届いた数10個はそのまま残します。

| 選択肢 | 選ぶとどうなるか |
|---|---|
| 実際に受け取った数も、数えた数に訂正する（確定） | 届いた総数も今回入力した数へ訂正する。単なる残りの確認には使わない |
| 実際に受け取った数を、数えた残りから逆算する（それまでに使った・渡した・分けた数を足す。仮の数） | 減らした記録と残りから、届いた総数を仮の数として求める。上の例なら3＋6＝9個 |
| 実際に受け取った数は変えない（現在の残数の確認） | 届いた総数を変えず、現在の残りだけを確認する |

この欄は表示の数（ラベル・パッケージ）・だいたいで受け入れた物に限りません。分割後の子など、表示されない対象もあります。逆算は、途中の数量が不明、受け取り後に数え直し済みなどの場合にはできません。以前の数を合わせるために、存在しなかった使用や受け取りを追加しないでください。

## 材料を使って製作する

**製造・工程**を選び、続いて行う**操作**を選びます。作業を始める数は、これから作る製品の数量です。Rを20台作るなら20台と入力し、材料のネジ80本などは別の材料欄へ入力します。作業終了には、そのうち今回終えた製品の数量を入れます。

1. **作業の開始（材料の使用とまとめて記録）**で工程、新しいID、製品、案件・用途、場所、作業を始める数・根拠を入力します。
2. 材料の欄で、実際に使った保管単位と数量・根拠を入力して記録します。同じ使用を先に単独の**使用**でも記録しないでください。
3. 作業を終えた分に**作業終了**を記録します。対象、新しいID、今回の数量を入力します。
4. 確認の完了を必要とする工程では、確認待ちの対象に**確認の完了**を記録します。
5. 次工程へ渡した分は**次の作業へ渡す**で、対象・新しいID・数量・移動先を記録します。外へ出すときは**外へ出す（譲渡・持ち出し）**を使います。

一部だけ進めると、残った分と次へ進んだ分のIDが分かれます。毎回、現在の作業の状態に合う対象を選びます。

部品100個から30個を使って30台の作業を開始し、10台の作業と確認を終え、うち5台を次工程へ渡した例では、材料は70個、元工程の作業中は20台、完成（渡す前）は5台です。工程完了累計10台には、既に渡した5台も含まれます。累計を現在の在庫へ足しません。

中断した場合は**作業の中断**、再開した場合は**作業の再開（材料の受け取りとは別に記録）**を使います。材料が届いただけでは自動再開しません。

## セットを使う

### 受け取り予定を展開する

1. **受け取り・割り当て・返却**の**セットの登録・変更**で、製品と構成を登録します。
2. **セットからまとめて受け取り（欠品の入力）**で案件・用途・セット・製作数を選びます。
3. 中間組立品の行では、組立済みで受け入れるか、自作分の部品で受け入れるかを選びます。
4. **予定数を展開**を押し、今回実際に受け入れる対象と欠品を確認します。欠品がある場合は**欠品の手配先**を入力します。
5. 数量・根拠・場所を確認し、確認欄にチェックして記録します。
6. 在庫と、欠品分に自動作成された依頼・未着を確認します。同じ欠品の依頼を別に重ねて登録しません。

予定を展開しただけでは在庫は増えません。組立済み品の不足を、その構成部品の不足へ勝手に分けることもありません。

### 作業の開始時の使用候補を出す

1. **製造・工程**の**セットで作業を開始（材料の使用を推計）**を選びます。
2. 工程、新しいID、製品、案件・用途、場所、作業を始める数・根拠を入れ、セットを選びます。
3. **使用候補を出す**を押します。
4. 明細ごとに**使う**か**除外**を選びます。使う明細は保管単位と今回の使用数を確認します。
5. 同じ材料を複数の箱から使う場合は**保管単位を分ける**で内訳を追加します。80本を箱Aから50本・箱Bから30本使うなら、最初の内訳を50本に直し、追加した内訳を30本にします。合計80本を確認します。
6. セットにない別の材料は、下の**手入力の材料1の保管単位（セットにない材料）**などの欄で対象を選び、根拠と使用数を入力します。同じ材料の箱違いはここへ重ねず、手順5の内訳に入れます。
7. 全明細と算出との差を確認し、確認欄にチェックして記録します。

候補は「1台あたり×作業を始める数」です。20台の作業を始めていても今回5台分しか使っていなければ、今回使った数量へ直します。既定の根拠は「だいたい」です。使用数全体を数えた内訳だけ**数えた**を選びます。残りの在庫を数え直したことにはなりません。

中間組立品はその組立品のまま候補に出ます。例えば完成品Rが組立品Xを1台使う構成なら、作業の開始では使用するXの現物を選びます。Xを自作したときの部品使用と、Rを作るときのXの使用を区別するため、Xの下位部品まで重ねて使用候補にしません。Xは自作した物でも、組立済みで受け入れた物でも構いません。自作する場合は、Xの製作と材料使用を別の作業として記録します。

一方、受け取りでは今回届く物がXなのか、その部品なのかを選ぶため、経路によって部品へ展開します。同じ入力内で、推計した材料を手入力欄にも重ねると拒否されます。別の操作で既に記録した使用まで自動で見つけるものではありません。

親子構成の作成、改訂の取り込み、単位の条件は[組立セットの詳しい操作](06-sets.md)にあります。

## 戻ってきた物を扱う

外から返ってきた物は、過去の引渡しをなかったことにする取消とは区別します。**やり直し・修理**の分類で**返ってきた物を仮の記録に残す（まだ数量へ反映しない）**、続いて**返ってきた物の仮の記録を割り当てる（現在数量への包含を確認）**を使います。

1. 戻った物の品目・場所・数量と根拠・元情報を仮の記録として残します。この時点では在庫へ二重に加えません。
2. 返ってきた物の記録を選び、既存の在庫数に含まれているかを確認します。
3. 含まれている場合は既存の対象へ対応付けます。含まれていない場合は、新しいID・品目・単位・案件・用途・場所を指定します。
4. 理由を入力し、内容を確認して割り当てます。理由などを直した場合は確認欄も再確認します。
5. 戻った現物と使用可否確認待ちの状態を確認します。

新しく割り当てた返ってきた物をやり直し・修理するときは、**返ってきた物のやり直し・修理を開始**で対象・工程・完了基準・新しいID・数量・理由を指定し、今回の物理作業を始めることを確認します。数が不明の場合は先に確認します。使用可否確認待ちはそのまま引き継ぎます。

手元の完成（渡す前）の物をやり直す場合は、**やり直し・修理を開始（同じ現物を工程へ戻す）**を使います。交換部品の使用、取り外した部品の廃棄・回収は、それぞれ実際に行った処理として記録します。やり直し・修理開始だけで元の材料使用を再計上しません。

## 記録の間違いを直す

| 状況 | 使う操作 |
|---|---|
| 現在の数量が違う。原因は不明 | 数えて確認・訂正（原因不明でもよい） |
| 間違いの疑いを伝えたいが、まだ数えられない | 数の食い違いをメモする（数量は変えない） |
| 記録した使用・引渡し自体が誤り | 間違えた記録の取り消し（使用・引渡し）。取消可能な対象か確認する |
| 実際の日時だけが違う | 実際の日時の訂正 |
| 届いた総数が違う | 実際に受け取った数の訂正（届いた数の訂正。理由が必要） |
| 依頼へ対応付けた届いた数・使える数が違う | 割り当ての訂正（届いた数・使える数。取消済みの依頼の割り当ても） |

作業の開始に対応付いた材料使用は単独取消できません。推計で記録した使用数を直す場合も、対象の保管単位全体を数え直します。

別記録を後から入力するときは、**別記録・元の資料からの後入力**を使い、元の資料と動きを識別する情報を揃えます。数え直しより前の操作なら、既にその数に含まれているかも確認します。含まれているか分からないまま、もう一度増減させないでください。

## 確認が必要な記録を調べる

1. **確認・履歴**で、問題の理由・対象・元の操作を確認します。
2. 対象の詳細と元の資料を見比べます。
3. 必要な数え直し・訂正を行います。
4. **数え直し・訂正・照合**の**確認事項を片付ける**で、対象と解消の仕方を確認します。

**適用する**は保留された操作を数量へ反映する判断です。件数を0にする目的だけで押さないでください。数が不明やだいたいであること自体は、すべて確認が必要になるわけではありません。
