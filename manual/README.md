# fuzzy-stock-system ユーザーガイド

手元にある物の数と、その数を確かめた根拠を記録するためのガイドです。

## まず押さえること

- 1台・1人・1タブで使います。記録は開いた端末のブラウザー（同じアドレス・同じプロファイル）に保存され、別端末とは共有しません。外部への送信もありません。
- 数が分からないときは`0`にしません。未確認の箱は数量の根拠を「数が不明」にして残します。「数えた・0」は空箱を確認した記録です。
- 予定・依頼・現物の動きは分けて記録します。必要な数や補充依頼を入れただけでは在庫は変わりません。実際に届いたときや使ったときに、それぞれの操作を記録します。

## ガイドの構成と読み方

初めて使うときは「1. はじめに」だけを最初から順に通読してください。それ以外のガイドは日々の作業や調べたい場面に応じて必要な節だけを引きます。

## このガイドの対象

このガイドはv1.5.0の操作を説明します。セットからの必要明細の生成と操作モードの切り替えは、v1.4.0から使えます。手順の例に出てくる品目・担当者・案件IDは架空の値です。

配布ZIPを使う場合は、同梱の`release-manifest.json`にあるソース版と、案内された対象版を照らし合わせてください。ここにある手順はソースコードと自動試験を照合して作成したもので、最終配布版を利用者が実機で操作した結果ではありません。

このガイドは配布ZIPとリポジトリの`manual`フォルダーにあります。画面上部の「使い方」から短いガイドも開けます。実際の業務で使う前に、次を決めておいてください。

- 記録する人と、使う端末・ブラウザーのプロファイル
- 記録の対象にする品目と場所
- バックアップを取る頻度と保管先、復元する人

決めたら、試験用のプロファイルで「1. はじめに」を一通り試し、バックアップから復元できることを確かめてから本番の記録を始めます。
