## このガイドの対象

2026年10月26日更新。v1.1.2を対象にしています。単一端末・一名で使い、記録はその端末のブラウザーに保存します。セットでの材料使用推計と、タブ終了後の入力回収を含みます。古い配布版では操作が揃わない場合があります。手順の例に出てくる品目・担当者は練習用の架空の名前です。

配布ZIPを使う場合は、同梱の`release-manifest.json`にあるソース版と、案内された対象版を確認してください。ここにある手順はソースと既存試験を照合して作成したもので、最終配布版を利用者が操作した結果ではありません。

このガイドは配布ZIPとリポジトリの`manual`フォルダーにあります。画面上部の「使い方」からは、ブラウザーで読める短いガイドを開けます。

実際の業務で利用する前には、端末・保存先・担当・対象品目・バックアップ方法を決め、[実機・業務の確認表](05-checklist.md)で確認します。
