# fuzzy-stock-system v1.1.2

手元の物の数と、その数を確かめた根拠を記録するソフトです。Windows、Windows PowerShell、JavaScriptが有効なブラウザーを使います。動作を確認しているブラウザーはMicrosoft Edgeです。Node.jsや開発用パッケージの導入は不要です。

## 起動する

1. ZIPを右クリックし、「すべて展開」を選ぶ。中のフォルダー全体を同じ場所に置く。
2. 展開先の `start-local.cmd` をダブルクリックする。
3. ブラウザーに表示された在庫一覧と「保存の状態」を確認する。起動用の黒い画面を閉じると配信が終了する。

既定のアドレスは `http://127.0.0.1:4180/` です。ポートを変える場合は、起動用ファイルの隣に `local-settings.txt` を作り、`port=4190` のように1行だけ書きます。アドレスを変えると別の保存先になります。前の記録が空に見えた場合は、元のアドレス・ブラウザー・プロファイルを確認してください。

ポートが使用中と表示された場合は、起動済みのこのソフトの黒い画面を閉じるか、ポート設定を確認します。アクセス拒否（エラー10013）は、端末が予約したポートに当たっている場合があります。`local-settings.txt`でポートを変えると起動できる場合があります。ポートを変えると保存先も別になるため、元の記録は元のアドレスで確認してください。解消しない場合やそれ以外の起動エラーは、黒い画面の内容とエラー番号を控え、端末の管理担当者へ確認してください。

## 最初の登録と使い方

初回起動では品目・場所・担当者が空です。在庫画面の「はじめに」から、記録する人、場所、品目と単位を順に登録します。画面上部の「使い方」から短いガイドを開けます。詳しいガイドは、このZIPの manual/README.md から読みます。水12本の登録と2本の使用を練習できます。

一台・一人・一つのタブで使います。在庫記録は外部へ送信しません。

## 記録を保管する

記録は同じ端末・同じブラウザーの同じプロファイルに保存します。別の端末やブラウザーとは共有しません。プライベートウィンドウは使わず、ブラウザーの保存データを消さないでください。

「管理」から「復元用バックアップを保存」でJSONファイルを書き出し、別に保管します。「閲覧用に出力」のExcelファイルは読むためのもので、復元には使えません。保存結果不明や一部保存が残る場合は、画面の照会・再試行で結果を確かめてからバックアップします。

記録には一つのタブを使います。「更新競合の照合」が出たら、元入力を控え、最新の記録と照合してください。次の入力回収が未有効、または共有退避に失敗した場合は、タブを閉じる前に原文を控えます。照合結果を保存しただけでは、元の業務操作は登録されません。入力し直す場合も、最新の記録で二重登録にならないかを確認します。

再開時は同じアドレス・ブラウザー・プロファイルを使います。前の記録があるときに初期化する必要はありません。初期化の確定は保存記録を置き換えます。

## タブ終了後の元入力を回収する

1. 「保存した」を確認して復元用バックアップを控え、このアプリを開いている操作中以外のタブを閉じる。
2. 「管理」の「タブ終了後の入力回収を有効にする」を押して確認し、「タブ終了後の入力回収：有効」と表示されたことを確かめる。
3. 更新競合が起きたら「回収した元入力」の件数と、保存中・失敗の表示がないことを確認する。同じアドレス・ブラウザー・プロファイルなら、タブやブラウザーの終了後も一覧を参照できる。
4. 一覧を開いて原文を控え、「この元入力を照合する」で最新の記録と照合する。別世代の元入力は参照と取下げだけに使い、現在の台帳へ照合結果を保存しない。不要なものは控えを確認してから「本文を残さず取り下げる」を選ぶ。

入力中の内容をすべて常時保存する機能ではありません。共有退避は解消・取下げ済みを含め64件・合計8MiBまでで、自動削除しません。容量不足や保存失敗の表示があるときは、元のタブを閉じず原文を控えてください。初期化・復元でも共有退避は保持します。有効化後の復元用バックアップには台帳と共有退避が含まれます。

## 更新する・旧版へ戻す

1. 旧版で「保存した」を確認し、復元用バックアップを保存する。旧版のフォルダーとバックアップを残す。
2. 未確定の入力を確認してから旧版のタブをすべて閉じ、起動用の黒い画面も閉じる。新版を別のフォルダーへ展開する。ポート設定を変えていた場合は同じ設定を使う。
3. 新版を起動し、前と同じアドレス・ブラウザー・プロファイルで記録を確認する。読めないときは初期化せず、保存したバックアップと旧版を保管する。

新しい記録を旧版が読めない場合があります。同じ保存版番号でも追加情報に未対応の過去の版へは戻せません。旧版へ戻す場合は更新前のバックアップを使い、更新後の記録を失う範囲を確認します。新版で追加した記録を旧版へ自動変換する機能はありません。

入力回収を有効にした保存先では旧版を起動しないでください。旧版が移行前の保存内容を書き換えると、新版は書込みを止めて照合を求めます。有効化後のバックアップは新版専用です。旧版の確認が必要な場合は別の保存先を使い、更新前のバックアップを使ってください。

旧版を確認する手順は次のとおりです。

1. 新版の「保存した」を確認し、新版のバックアップも別名で保存する。新版のタブと起動用の黒い画面を閉じる。
2. 旧版のフォルダーの `start-local.cmd` と同じ場所に `local-settings.txt` を作り、これまで使っていないポートを指定する。例は `port=4190`。新版の設定は変えない。
3. 旧版を起動し、アドレスが指定したポートであることを確認する。記録が既にある場合は復元せず、別の未使用ポートを選ぶ。
4. 更新前に旧版で保存したバックアップを復元し、内容を確認する。新版で作った記録をこの保存先へ持ち込まない。
5. 新版へ戻るときは旧版のタブと黒い画面を閉じ、新版を元の設定で起動する。

版番号は配布元のRelease名（例：v1.1.0）で確認します。ソース版と各ファイルのSHA-256は `release-manifest.json` にあります。
