# fuzzy-stock-system v1.4.0

手元にある物の数と、その数を確かめた根拠を記録するソフトです。Windows、Windows PowerShell、およびJavaScriptが有効なブラウザー（動作確認済みはMicrosoft Edge）で動作します。Node.jsや開発用ツールの導入は不要です。

## 起動する

1. 配布ZIPを右クリックして「すべて展開」を選び、展開先のフォルダー一式を同じ場所に置く。
2. 展開したフォルダー内の `start-local.cmd` をダブルクリックする。
3. ブラウザーに開いた在庫一覧と上部の「保存の状態」を確認する（起動用の黒い画面を閉じると配信が終了するため、使用中は開いたままにする）。

既定のアドレスは `http://127.0.0.1:4180/` です。ポート番号を変える場合は、`start-local.cmd` の隣に `local-settings.txt` を作り、`port=4190` のように1行だけ記述します。アドレス（ポート）を変えるとブラウザー内の保存先も別になります。以前の記録が空に見えたときは、前回と同じアドレス・ブラウザー・プロファイルで開いているか確認してください。

「ポートが使用中」と出た場合は、すでに起動している黒い画面を閉じるかポート設定を確認します。「アクセス拒否（エラー10013）」は端末が予約しているポートと重なった場合に発生するため、`local-settings.txt` で未使用ポートへ変えると起動できることがあります。解消しない場合は黒い画面のメッセージとエラー番号を控え、端末の管理担当者へ確認してください。

## 最初の登録と使い方

初回起動時は品目・場所・担当者が未登録です。画面の「はじめに」の案内に沿って、担当者、置き場所、品目と単位を順に入力します。

画面上部の「使い方」を押すと、ブラウザー上で要点ガイドを読めます。詳しい手順書はこのZIPの `manual/README.md`（PDF版は `manual/README.pdf`）から開けます。初回は `manual/01-getting-started.md`（または同名のPDF）に沿って、水12本の登録と2本の使用、バックアップと再開までを試してください。

1台の端末・1人の担当者・1つのタブで使います。入力した在庫記録を外部へ送信する機能はありません。

## 記録を保管する

記録は同じ端末・同じブラウザー・同じプロファイルの中に保存され、別端末や別ブラウザーとは共有されません。プライベートウィンドウ（InPrivate）は使わず、ブラウザーのサイトデータを消去しないでください。

日々の作業後は行き先「管理」の「復元用バックアップを保存」からJSONファイルを書き出し、別の保管場所にも控えておきます。「閲覧用に出力」のExcelファイルは閲覧専用であり、復元には使えません。保存結果不明や一部保存が出ているときは、画面の照会・再試行で確定させてからバックアップを取ります。

「更新競合の照合」が表示された場合は、元の入力内容を控え、最新の記録と照合します。次節の入力回収が未有効、または退避に失敗しているときは、タブを閉じる前に必ず画面上で原文を控えてください。照合結果を保存しただけでは元の業務操作は登録されないため、最新の記録を確認したうえで必要な操作を入力し直します。

翌日再開するときは、同じアドレス・ブラウザー・プロファイルで開くだけで前回の続きから使えます。初期化は保存データを置き換える操作なので、通常利用では行わないでください。

## タブ終了後の元入力を回収する

1. 「保存した」を確認して復元用バックアップを取り、操作中以外のタブをすべて閉じる。
2. 「管理」の「タブ終了後の入力回収を有効にする」を押して確認し、「タブ終了後の入力回収：有効」と表示されたことを確かめる。
3. 更新競合が起きたら「回収した元入力」の件数と、保存中・失敗の表示がないことを確認する（有効化済みなら、タブやブラウザーを閉じた後でも同じアドレス・プロファイルで一覧を参照できる）。
4. 一覧を開いて原文を控え、「この元入力を照合する」で最新の記録と照合する。別世代の元入力は参照と取下げだけに使い、現在の記録へ直接照合結果を保存しない。控えを確認した後に一覧から外すときは「本文を残さず取り下げる」を選ぶ。

入力途中の下書きを常時保存する機能ではありません。共有退避の上限は解消・取下げ済みを含めて64件・合計8MiBまでで、自動削除は行いません。容量不足や保存失敗が出たときは、タブを閉じずに原文を控えてください。有効化後の復元用バックアップには、在庫記録と共有退避の両方が含まれます。

## 更新する・旧版へ戻す

1. 旧版で「保存した」を確認し、復元用バックアップJSONを保存する。旧版のフォルダーとバックアップは消さずに残す。
2. 未確定の入力がないことを確認し、旧版のタブと起動用の黒い画面を閉じる。新版を別のフォルダーへ展開する（ポート設定を変えていた場合は同じ設定を使う）。
3. 新版を起動し、前回と同じアドレス・ブラウザー・プロファイルで記録を確認する。読み込めないときは初期化せず、旧版とバックアップを保全する。

新版で保存した記録やバックアップは、古い版では読み込めない場合があります。旧版へ戻すときは更新前に保存したバックアップを使うため、更新後に入力した記録は含まれません。

また、入力回収を有効にした保存先では旧版を起動しないでください。旧版を確認したい場合は、次の手順で別のポート（別の保存先）を使って開きます。

1. 新版の「保存した」を確認し、新版のバックアップも別名で保存してから、新版のタブと起動用の黒い画面を閉じる。
2. 旧版のフォルダーの `start-local.cmd` と同じ場所に `local-settings.txt` を作り、未使用のポート（例：`port=4190`）を指定する。新版側の設定は変えない。
3. 旧版を起動し、アドレスが指定したポートであり、記録が空であることを確認する。
4. 更新前に旧版で保存したバックアップを復元して内容を確認する。新版で作った記録はこの保存先へ持ち込まない。
5. 新版へ戻るときは旧版のタブと黒い画面を閉じ、新版を元の設定で起動する。

版番号は配布元のRelease名（例：v1.4.0）で確認できます。ソース版と各ファイルのSHA-256ハッシュは同梱の `release-manifest.json` に記載されています。
