# 3. 画面と用語

[目次](README.md) · 前へ：[作業別ガイド](02-guide.md) · 次へ：[困ったとき](04-troubleshooting.md)

## 五つの行き先

| 行き先 | 見るもの・行うこと |
|---|---|
| 在庫と入力 | 在庫一覧を絞り込む。IDから詳細と履歴を見る。操作を入力する |
| 不足・依頼・案件・用途 | 必要な数、不足、依頼、到着と割り当て、案件・用途ごとの状況、供給の履歴を見る |
| 確認・履歴 | 確認が必要な記録と履歴を調べる |
| 登録情報 | 品目・場所・案件・用途・担当者などの登録内容を確認する |
| 管理 | バックアップ、復元、閲覧用Excel出力、試験データへの初期化を行う |

画面が狭いと、**入力**は在庫一覧の下へ移ります。横に長い表は、表の中を横スクロールして右端を確認します。

## 入力するときの選択

**作業の種類**は、操作の候補を絞る欄です。種類を選んだ後、**操作**も選んでください。種類だけ変えても、入力中の操作は残ります。別の操作を選ぶと入力欄が切り替わります。

| 作業の種類 | 主な用途 |
|---|---|
| 現物の登録・使用・移動 | 登録、使用、出庫、移動、分割、統合、案件・用途の付け替え、取り分け |
| 製造・工程 | 作業の開始、セットでの作業開始、作業終了、確認の完了、次工程への移動、中断と再開 |
| やり直し・修理 | やり直し・修理の開始、交換部品、廃棄・回収、返ってきた物の受付と割当 |
| 必要な数・依頼・発注 | 必要な数、不足申告、依頼、注文の確定、回答、取消 |
| 受け取り・割り当て・返却 | 受け取り、セット、割り当て、実際に受け取った数と割り当ての訂正、余剰、返却確認 |
| 数え直し・訂正・照合 | 現物の再確認、数の食い違いのメモ、実際の日時の訂正、間違えた記録の取り消し、照合 |
| 仮の記録・所属の整理 | 対象不明の記録、品目や所属の整理 |
| 登録情報の登録・変更 | 品目・場所・案件・用途・担当者の登録、名称・品番・コード・利用状態などの変更 |

キーボードでは、目的の選択肢を選んだことを確認してからTabで次へ進みます。Tabだけでは選択内容は変わりません。

セットからのまとめて受け取り・セットによる作業開始・返ってきた物の割当などには、内容を確認したことを示すチェック欄があります。これらはチェックしてから記録します。入力を変更してチェックが外れたら、変更後の内容を読み直してチェックしてください。通常の登録・使用には、この確認チェック欄はありません。

## 新しいIDを決める

保管単位のIDは、現物の箱・袋・束などを区別する名前です。同じ品目でも箱が二つあれば、別のIDで管理できます。現場の通し番号も、同じ台帳内で重複しなければ使えます。品目の品番・コードとは区別してください。

| 場面 | 名前の例 |
|---|---|
| 最初の箱を登録する | `P-01` |
| その箱から一部を分ける | `P-01-B` |
| 作業を始める製品を記録する | `W-001` |
| そのうち作業が終わった分を記録する | `W-001-F1` |

これは命名例で、必須の形式ではありません。IDは自分で入力します。空欄や空白だけのIDは使えず、既に使ったIDでは新しい保管単位を作れません。「使用済み」と表示されたら既存の対象を確認し、別の新しいIDを付けます。使い切った箱や統合元のIDも再利用しません。

## 数量を読む

| 言葉 | 意味 | 例 |
|---|---|---|
| 保管単位 | 一つの箱や束など、ひとまとまりとして管理する現物 | `GUIDE-P-01`の箱 |
| 単位 | 数量を表す単位 | 個、本、箱、台 |
| 数えた | 対象を数えたことに基づく数量 | 箱の中を数えて12個 |
| 表示の数（ラベル・パッケージ） | 中身を数えず、ラベルなどの記載を使った数量 | ラベルに100本 |
| だいたい | 見積もりや推計に基づく数量 | およそ80本 |
| 数が不明 | 数字として分からない数量 | 中身未確認の箱 |
| 記録上の数 | 登録・使用などの記録から求めた現在数 | 12個から2個使用して10個 |
| 確認が必要 | 記録同士の関係や適用可否など、確認する問題がある状態 | 数え直し以前の使用を後から入力 |

**数が不明な場合は0ではありません。** 空欄で記録する場合も、数量の根拠を「数が不明」にします。「数えた」のまま数量を空欄にすると、入力不足になります。

| 分かっていること | 数量の根拠 | 数量欄 |
|---|---|---|
| 数えて空だと確認した | 数えた | `0` |
| 数えて12個だった | 数えた | `12` |
| 見積もるとほぼ残っていない | だいたい | 見積もった値。`0`ならだいたい0 |
| 数が分からない | 数が不明 | 空欄 |

分からないまま「数えた」と0を選ぶと、「数えて空だと確認した」記録になり、在庫や不足の判断を誤らせます。数字だけでなく根拠も合わせて選びます。

「約」や中身未確認の表示があるときは、数値だけを確定数として使わないでください。使用分を数えたことと、残っている箱全体を数えたことも別です。個と箱など、異なる単位の数をそのまま足しません。

## 混同しやすい状態

| 表示・記録 | 意味 |
|---|---|
| 必要な数 | 案件・用途で必要な品目と数量 |
| 不足 | 必要な数と使用済み・使用可能な在庫などから判断する不足。条件によって判定不能になる |
| 依頼 | 補充などを依頼した記録。まだ現物が届いた意味ではない |
| 未着 | 依頼に対して届いていない分 |
| 実際に受け取った数 | 実際に届いた現物の数量 |
| 届いた数 | 受け取りのうち、その依頼の到着として対応付けた数量 |
| 使える数 | 到着分のうち、不足の解消に充てた数量 |
| 取り分け | 不良・使用可否確認待ち・返却待ち・予備など、使用対象から外している状態。現物がなくなった意味ではない |
| 作業の状態 | 作業なし、作業中、確認待ち、完成（渡す前）などの位置付け |

「在庫一覧の絞り込み」の品目・案件・用途・場所は、表示を絞る欄です。同じ名前でも、**入力**区画の欄は記録する値なので、操作前に区画を確認してください。

## 日時・名称・担当者

- **実際の日時**は実際に物が動いた時点です。画面の日時は日本時間です。分からない場合は不明を選び、推測して埋めません。
- **入力した日時**はシステムに入力した時点です。後入力では実際の日時と異なります。
- **品番・コード**は品目・場所・案件・用途を見分けるコードです。**保管単位のID**は箱や束を区別します。
- 新しい履歴には、記録当時の品目名・コードが残ります。現在の登録情報名と違う場合があります。旧履歴にない情報は、現在名から補って表示しません。
- **記録する人**の選択は記録者の指定です。本人認証や操作権限の制御ではありません。

## 以前の表示との対応

v1.1.0では画面とExcel出力の用語を変えました。過去の入力原文や操作名は、そのまま残る場合があります。

| 以前の表示 | v1.1.0の表示 |
|---|---|
| まとまり・保管・使用単位 | 保管単位 |
| 案件・案件所属 | 案件・用途 |
| 案件間振替 | 案件・用途の付け替え |
| レシピ・受入テンプレート | セット |
| 実数確認 | 数えた |
| ラベル値 | 表示の数（ラベル・パッケージ） |
| 概算 | だいたい |
| 数量不明 | 数が不明 |
| 台帳数 | 記録上の数 |
| 要照合・照合事項 | 確認が必要・確認事項 |
| マスタ | 登録情報 |
| 管理コード・管理名称（部署内） | 品番・コード・呼び名 |
| 入り数 | 1包装あたりの数。箱なら1箱、袋なら1袋の中身の数 |
| 元資料 | 元の資料 |
| 発生日時・記録日時 | 実際の日時・入力した日時 |
| 受入・充当 | 受け取り・割り当て |
| 着手・工程状態 | 作業の開始・作業の状態 |
| 手直し・戻り | やり直し・修理・返ってきた物 |

数量の意味は変わりません。「記録上の数」は記録から求めた値、「数えた」は現物を数えた根拠です。不明は0として扱いません。使用対象からの除外は「取り分ける」、解除は「取り分けを戻す」になりました。現物がなくなる操作ではありません。
