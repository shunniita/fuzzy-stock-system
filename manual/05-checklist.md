# 5. 利用確認チェックリスト

[目次](README.md) · 前へ：[困ったとき](04-troubleshooting.md)

最終候補を実際に操作し、手順どおりに進めるか、結果が合うかを確認します。以下の結果はすべて未実施です。確認した欄だけに結果を記入してください。

## 確認前に記録する

| 項目 | 記入欄 |
|---|---|
| 確認日・担当者 | 未記入 |
| ソフト版・ZIP名 | 未記入 |
| Windows・Edgeの版 | 未記入 |
| 試験用プロファイル・アドレス | 未記入 |
| バックアップの保管先 | 未記入 |

業務用とは別の通常プロファイルを使います。ブラウザー終了後の保存を確認するのでInPrivateは使いません。途中で期待と違う結果になったら、数を合わせる追加操作をせず、最後の操作と実際の値を記録します。

記録する人は一名、アプリのタブは一つにします。操作のたびに**作業の種類**と**操作**をそれぞれ選び、確認チェック欄がある場合は内容を確かめてチェックします。新しいIDは表の値を使い、再実施で「使用済み」と出たら、前回の試験データが残っていないか確認してください。

以下は対象業務に合わせた追加確認です。開始データと具体的な入力値を実施前に固定してください。A〜Dの合格だけで、これらを合格にしません。

| 項目 | 確認する流れと結果 | 結果 |
|---|---|---|
| 工程の設定 | 空の台帳で、完了基準の違う2工程を登録し、次工程の場所を1か所指定する。工程の名前を変えると一覧は新しい名前、履歴は記録したときの名前になる。利用停止した工程は作業の開始に出ない | 未実施 |
| 製作 | 工程を登録してから、作業の開始、一部作業終了、確認の完了、次の作業へ渡す。残った作業中・完成（渡す前）と累計を区別できる | 未実施 |
| 返ってきた物 | 出庫済みの現物を受付し、既存数量への包含を確認して割当。元の出庫は消えず、二重に増えない | 未実施 |
| やり直し・修理 | 返ってきた物からやり直し・修理開始。現物と元の材料使用を二重計上せず、交換部品だけ別に記録できる | 未実施 |

## F. 端末と外部の道具で確認する

- [ ] 実際に渡すZIPを、対象Windowsで展開して起動できる。
- [ ] 狭い画面や200%拡大でも入力でき、表の右端まで確認できる。
- [ ] キーボードで目的の操作を選び、入力・確認・取消ができる。
- [ ] 最終候補からのExcel出力を実Excelで開き、保存・終了・再オープンして、先頭ゼロ・長い値・不明と0・当時の名称を確認できる。
- [ ] リーダーを使う場合、実機の終端文字・連続入力・対象確認・手入力代替を確認できる。
- [ ] 担当、端末、対象品目、バックアップ頻度・保管先、復元担当が決まっている。

### 実Excelで出力を確認する

1. 練習用の記録で、品番・コードが`0012`の品目と、名前が`=1+1`の品目を用意します。長い名前も一つ用意し、入力した原文を別に控えます。
2. 数が不明な物と0個の物を登録し、閲覧用Excelを出力します。
3. Microsoft Excelで開き、先頭のゼロが残ること、`=1+1`が計算結果の2にならず文字列のままであること、長い名前の全文、不明と0の区別を確認します。
4. 別名で保存し、Excelを終了して再度開き、同じ内容を確認します。画面とファイルの記録を照らして結果を残します。

この確認は対象端末の実Excelで行います。ファイルの生成試験や別の表計算ソフトでの成功だけでは合格にしません。

現場の条件・所要時間・利用許可は、下の結果表へ記録してください。外部への問い合わせには架空の値を使い、実資料は送らないでください。

## 結果を残す

結果は「合格・不合格・未実施・適用外」を使います。適用外には理由を記入します。

| 項目ID | 結果 | 実際の値・表示 | 迷った箇所・説明の要否・所要時間 | 再確認する版・結果 |
|---|---|---|---|---|
| 未記入 | 未実施 | 未記入 | 未記入 | 未記入 |

不合格の場合は、最後に選んだ対象・押したボタン・入力値を記録します。修正後の結果は別行に追記してください。この表の合格は記載した版と条件での確認結果です。全要求の適合や実運用開始の承認は、別に判断します。
